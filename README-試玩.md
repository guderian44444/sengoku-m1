# 吞食戰國 v0.33 試玩說明

目前開放新版信長、阿市、秀吉、家康、顯如與忠勝。既有玩家、六人的裝備、倉庫、金錢、成就與關卡進度保留。支援單人、同機雙人及前三大關。第二關通關後開放第三關「今川本陣」；`啟動第三關試玩.cmd` 可直接體驗，使用隔離資料且不寫回正式角色進度。

開啟 `啟動戰鬥原型.cmd` 進入主選單；`啟動鍵盤練習場.cmd` 直接練習。雙人請連接兩支手把後開啟 `啟動雙人合作.cmd`。練習場按 Tab 可在六名角色間切換。

選單採古文書紙色、墨字、朱紅焦點與回紋；介面和戰鬥資訊統一使用隨附的「莫大毛筆」字型，罕字保留隨附字庫補字。主畫面為日文草書標題與英文副標「SENGOKU CONQUEST」。

選單用十字鍵／左搖桿移動，×／A 確認、○／B 返回。L1／R1 可直接換欄位（倉庫頁為切換分類）；清單用上下選物品、左右離開，右搖桿捲動長說明。紅框是目前操作位置，下拉清單按返回只會先關閉清單。

姓名、IP 或連線埠欄位按 ×／A 可開畫面字盤；L1／R1 切換常用姓名字、英文大小寫與數字符號，□／X 刪字，Options／Start 確認，○／B 取消並保留原文字。姓名字盤可按「換頁」找字；完整中文輸入仍可直接使用實體鍵盤與系統中文輸入法。玩家姓名最多 20 字，完成輸入後按「新增玩家」建立獨立存檔。

| 操作 | 鍵盤 | 手把 |
|---|---|---|
| 移動／雙點衝刺 | WASD | 左搖桿／方向鍵 |
| 輕手 | J | □／X |
| 重手／蓄力 | K | ○／B |
| 抓技 | L | R2／RT |
| 跳 | 空白 | ×／A |
| 拾取 | E | L1／LB |
| 暫停／選單 | Esc | Options／Start |

輕手每次按鍵播放一段，可提前再按銜接下一段；白板恢復上一版每段約 0.32 秒、完整三段約 0.95 秒的節奏，第三段擊飛。按住輕手不會自動放完整三段。

前三關共 17 場景使用 PeriTune 配樂，依接敵、敵將、雙將與義元戰切換，勝利短曲結束後接結算循環；來源與署名隨附於 `game/audio/peritune-campaign-v1/CREDITS.txt`。主選單、演武場仍使用現有 v35 配樂。

重手點放：近身重手與普通刀劍劍氣會把小兵短距離擊飛；阿市單箭維持站立擊退。重手、蓄力重手及跳重手命中大小王只造成較長距離的地面擊退，不會擊倒。按住蓄滿後放開：信長旋斬兩圈、阿市貫穿箭；阿市滿蓄時上＋放開改為箭雨。家康在地面蓄滿重手（至少 0.9 秒）放開，施展拔刀前衝一閃。重手可被打斷。

六人的輕手每段前踏距離已加長。信長蓄力旋斬與跳＋重手範圍比前版增加 50%；顯如走路、跑步均播放完整移動動畫。武器揮空、命中、格擋、普通／蓄力射箭分開配音，各類音色有五種變化；第二關三位具名武將皆有出場白。

跳＋輕手：近身揮打，威力與範圍＋20%。跳＋重手：五位男性角色向下揮出大範圍劍氣，阿市朝前下方射近中遠三箭；大小王不會被擊倒。衝刺＋重手：前方擊飛，盾兵普通命中，王可格擋。

第三關木柵間距加長，每道木柵啟動後持續補兵，拆掉才停止；三道皆破後清完餘軍才能前進。警鐘木樁血量為原本三倍，鐘實際落地時播放撞鐘聲。兩位小王血量加倍、出招更積極；今川遠距離交替使用火槍速度的三箭扇形連射與巨大高速劍氣。詳見 [第三關 v41 調整](docs/STAGE03-V41.md)。

抓住後按輕手兩次打擊，第三次向前摔出，可撞飛其他人；反推方向立即過肩摔。武器、人物與特效分層，換裝會使用目前裝備的武器。

F1 開合戰秘卷，F11 切換全螢幕。演武場 1 木樁、2 抓摔、3 雜兵、4 遠程兵、5 敵將，R 重演。

每人三條命，每 10000 分加一命。奉卷軸令旨清敵破障，待「進軍」令下共同向右前進；第一關通關後可選第二關。出陣行囊最多兩把兵器、兩個護符；常備兵器不佔行囊且無限耐久。拾取不自動裝備，行囊滿時物品留在地上。軍議中可換裝、退出會先保存，保存失敗會留在遊戲中。

選單以方向鍵／左搖桿移動，×／A 確認，○／B 返回；L1／R1 換欄，右搖桿捲動。名號、IP 與連線埠欄位按 ×／A 開啟字盤；X 刪字、Start 確認、B 取消。亦可用鍵盤及系統中文輸入法。常用中文字盤不含所有漢字。介面採毛筆字與古文書配色，小兵血條為抬高的暗金細框。

舊方向派生招、防禦及獨立怒氣必殺已停用。封存檔、舊角色攻擊圖、生成來源與歷史測試不隨試玩包提供；走跑、受傷、場景、敵人、武器及現行配音音效仍為必要依賴。

招式格數、素材接點與驗證界線見 [COMBAT-V33](docs/COMBAT-V33.md)。此包為 Godot 引擎搭配原始資源的 Windows 免安裝試玩包，尚非正式 EXE／PCK 匯出；手把手感及真人連線另行驗收。
