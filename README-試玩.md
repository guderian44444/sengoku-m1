# 吞食戰國 M1 v0.27 操作說明

版本：sengoku-m1-0.27.0。Windows 64 位元 Godot 專案，六位主角、十二陣營可選，支援雙搖桿同機合作與依控制器支援的震動。目前第一關已具備七個長場景、十四據點、31 波攻防，其他 23 關仍是設計清單。

v0.22：信長、阿市、本多完成 77 動作組、462 格新姿態，每組六格；採與正式今川敵軍一致的畫風，身體與武器分層。信長頭側雙手立刀，三刀依下斬、上撩、橫切；阿市保留苗條腿型、白色內搭、長馬尾與簡單頭飾、背弓、轉身高踢與露肩慶祝；本多保留鹿角兜、念珠與蜻蛉切，槍底砸地產生震波。其他三位可選人物的既有造型保留。

v0.27 本機試玩修正：敵將開場與討取語音、勝利後移動拾取、退出／重開確認、物品受擊與材質音效；每段敵人加倍、長度縮為原本 2/3、補給限 1–2 件。小王武器 20%、大王 50%，敵將保證食物。阿市跳射改為斜下短程三箭（保留擊倒），上方向重擊為近／中／遠三支拋物線箭（不凍結、不擊倒）。詳細記錄見 [v0.27 試玩修正](docs/PLAYTEST-V27.md)。

v0.26 整合 DOT 的刀／槍／弓各 16 款，共 48 款武器、信長暗紅甲與阿市裙裝修正。選角「裝備」或戰鬥暫停「1P／2P 裝備與收藏」可查看目前裝備、收藏、能力和武器圖片，當場換裝後繼續戰鬥；收藏頁還可進入圖鑑。人物屬性與收藏裝備分玩家、分武將保存，大關進度共用；再次出陣從所選大關起點開始、滿血三條命。現在只開放第一大關。

v0.21：每人三條命，命數包含目前這條；死亡倒地約兩秒後滿血起身，保護三秒。積分各自累計、跨區保留，每 10,000 分加一命，HUD 顯示命數、積分與加命提示。命盡隊友保留倒地，另一位仍可繼續；訓練場免死、不計分。金剛／玄鐵／明鏡護符分別抵消 40／75／110 傷害，按 E／L1 拾取，不疊加，身上金／青／紫色光芒耗盡即消失。

玩家及敵人倒地、起身時免受擊；玩家起身會小範圍撞開包括王在內的敵人，只造成 2 點傷害，另有 45 tick 保護。大小王起身仍會震開站立的近身玩家，不重置正在起身的玩家。玩家最後一命死亡保持倒地，全滅時鏡頭留在倒地隊伍位置。尚未開放的右側區域不會顯示，GO 等待時也不提前露出；左側已清空區域可回頭撿補給。室內屏風、櫃子與戶外障礙會阻擋移動，堅固物件需更多命中；補血食物拾取有短音及角色亮邊。

名稱或形制有歷史背景，弓包含明示復原的形制，並非阿市遺物。階位、顏色與傷害／元素為遊戲設定，不是歷史兵器優劣排行。[48 款完整清單](HANDOFF.md#8-48-件-id-對照) 附對應 ID；圖鑑中的來源與授權提示保留。

靠近掉落物按 E／L1／LB 拾取，同類武器加入個人收藏並立即裝備；不同種類留在地上。正在裝備的重複武器也留給隊友。出陣選角時，武器欄可換回該玩家、該武將已取得的武器；沒有背包容量或鍛造操作。預設武器隨人物出陣，不會空手。

擊倒小王有 20% 機率、大王有 50% 機率提供未收藏的同類武器，並保證掉落食物，最高比目前裝備高兩階／三階。種類依造成致命傷的玩家選擇；持有最高階仍可補齊未收藏的同階與低階款式，收齊該類後停止掉落。效果依武器可增加傷害、距離、擊退或帶元素；阿市飛針、踢腿不吃弓箭武器加成，飛出的箭保留發射當下屬性。

正式一人出陣／二人共鬥每兩秒檢查變更，拾取、擊殺、離開戰鬥及退出程式也保存；暫停選單可按「保存人物」。存到 `user://characters-v1.json`，同一檔案以 1P／2P 與武將分開記錄，同武將雙人不會互相覆蓋。

保存總積分、永久生命加成欄位（目前預設 0）、已裝備武器與取得清單；大關只記目前關號與已通關關號，不記場景、據點、波次或行走位置。每次新出陣從大關起點開始、滿血三條命，下一次加命門檻依保存的總積分計算；目前 HP、剩餘命數、怒氣、護符、敵人或掉落物不存。工程訓練、素材展示與工程 IP 連線不寫正式人物存檔。

存檔失敗會提示。有效舊檔有 `.bak` 備份；主檔損毀可讀備份並保留損毀原件，兩份無效或未知版本時不自動覆寫。請保留原檔與備份再處理，測試工具使用獨立資料目錄。

## 開始試玩

使用 Godot 4.7.2 開啟 `game/project.godot` 後按 F5，在開始畫面按 Enter／Start，從主選單選「一人出陣」，選擇武將及難度後按「出陣」。本機引擎若已放在 `tools/godot-4.7.2/`，亦可使用「啟動戰鬥原型.cmd」。其他啟動腳本與引擎路徑見 `README.md`；「啟動六武將試戰.cmd」保留三波試戰，練習場可用 Tab 輪換角色。

同機雙人請接上兩支搖桿，雙擊「啟動雙人合作.cmd」以信長與阿市開始。想換角色，從主選單選「二人共鬥」，選擇一番隊、二番隊武將與難度，再按「出陣」。未接滿兩支時會留在選單提示連接。正式第一關使用今川軍，其他陣營在工程入口供練習／陣營試戰選擇。

WASD 移動；同方向在 0.25 秒內點兩下，第二下按住即可衝刺，放開或改方向停止。先進入衝刺再按 K，立即使出朝面前的衝刺重手，不進入蓄力。空白跳躍；J 輕擊；K 重擊／按住蓄力；I 按住防禦；L 按住抓人、放開摔；U 滿怒必殺；E 拾取。

由最下方「工程入口」進入練習模式：1 木樁、2 肉盾、3 三波敵軍、4 遠程兵、5 目前陣營小王；R 重置、Tab 輪換六人、F1 操作表、Esc 選單。陣營在工程入口選擇。

只有木樁模式自動滿怒；其餘戰鬥演練需靠命中、挨打或格擋累積至 100 才能用必殺。練習場玩家不會死亡，停止受傷約兩秒後回血。三波敵軍可被打倒，整波清完再出下一波；其他單項演練約兩秒後補回打倒的敵人。切離視窗會暫停單人模式並取消尚未完成的輸入，回來後放開按鍵再繼續。

## 操作與 COMBO

持續按住左右前進時連按輕／重手，普通移動會在出招與接續窗口暫停，連段結束或停打逾時後恢復。要使出方向突進，請同時新按左右方向＋J；W／S 的上下方向技照常。已進入衝刺時按 K 則直接出衝刺重手；未衝刺時按住 K 約 0.58 秒後放開為滿蓄，短按放開是普通重擊。方向在按下攻擊時決定。每段要重新按，長按 J 不會自動出完三下。連段仍有起手與收招窗口。完整六人對照亦可隨時按 F1 查看。

## 防禦、肉盾與擊飛

按住 I／L2，站在地面面向敵人可格擋正面小攻及箭彈；背擊繞過防禦，強攻會破防。成功格擋增加 10 怒氣，家康增加 14 並在正面破防時減傷。光秀成功格擋後約 0.75 秒內，維持防禦並按 J 可施放反擊斬。

按住 L 抓人，放開才飛摔；被抓敵人會掙扎，在0.5秒時有一次50%機會掙脫，沒有掙脫者最多抓三秒後放下。倒地、起身中或被擊飛的敵人不能抓。被抓的人可擋住正面箭彈與小攻並受傷；打倒型重攻和背擊仍能傷到持有者。投出去可以撞倒其他敵兵。

## PS5 搖桿、同機雙人與 IP 合作

左類比／十字鍵移動，同方向雙點後按住衝刺；□ 輕擊、○ 重擊／按住蓄力、× 跳躍、△ 按住抓人／放開摔、R1 滿怒必殺、L1 拾取、L2 按住防禦、Options 選單。衝刺中按○立即施放衝刺重手。Xbox 對應 X／B／A／Y、RB／LB／LT／Start，衝刺中按B為衝刺重手。方向＋按鍵與鍵盤相同。

選單用左類比／十字鍵選擇，×／A 確認、○／B 返回或取消；兩支搖桿都能操作。退出確認預設選「取消」，向下選「確認」後按 ×／A 才結束目前階段。

同機合作中兩支搖桿分別控制 1P、2P，鍵盤只控制 1P。共用鏡頭會限制兩人相距過遠，任一方按 Options／Start 都能暫停。切離視窗或拔除已分配的搖桿會取消蓄力／抓人並暫停，接回兩支、放開按鍵後再按繼續；不會因失焦而意外放出蓄力或投摔。

命中、挨打、格擋、抓取與必殺會對對應玩家的搖桿送出不同輕重震動，暫停、失焦與離開會停止震動。實際支援取決於搖桿、USB／藍牙模式與驅動，這不是 DualSense 自適應扳機功能。

雙方須使用相同版本。從最下方工程入口使用 IP 直連；主機選好角色、陣營與難度後建立雙人主機，客端填主機 IPv4 及 UDP 埠（預設 27860）加入。主機統一計算戰鬥。LAN 可直接測試；跨網路可能需設定防火牆與 UDP 轉發，目前沒有 NAT 穿透或中繼。斷線結束本次試戰，不保存進度。
