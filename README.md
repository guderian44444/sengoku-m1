# 吞食戰國

Godot 4.7.2 Windows 原生橫向動作遊戲，目前版本 **0.33.0**，整合至 v38 素材與音效修正。信長、阿市、秀吉、家康、顯如、忠勝六人可玩，既有角色存檔與收藏資料保留。

新版操作固定為輕手、重手、抓技、跳、拾取。信長 16 招／294 格、阿市 17 招／117 格，人物、可換裝武器與特效分離。每段輕手獨立播放、前踏並回正，第三段擊飛；重手集滿放開施放。詳細操作見 [試玩說明](README-試玩.md)，素材規格與驗證見 [COMBAT-V33](docs/COMBAT-V33.md)。

前三關「桶狹間竹林」、「大高兵糧道」及「今川本陣」可玩，支援同機雙人、裝備耐久、玩家分檔倉庫、護符、成就及退出保存。啟動 `啟動戰鬥原型.cmd`，或直接開啟 `game/project.godot`。第二關通關後開放第三關；直接體驗可用 `啟動第三關試玩.cmd`（隔離進度）。第三關整合與配樂見 [整合紀錄](docs/STAGE03-INTEGRATION-20261016.md)。

介面已整理為古文書風格，使用隨附的繁中毛筆字型、日文草書標題與英文副標；選單支援搖桿換欄、清單退出、說明捲動及姓名／IP 畫面字盤。操作與中文輸入方式見[試玩說明](README-試玩.md)，UI 驗證入口見 [UI-V34](docs/UI-V34.md)。

現行各頁樣式為原版正風毛筆MasaFont Regular動態黑字與02紅錦卷軸按鈕，取消額外加粗及文字黑描邊。[原生截圖、OFL與接入驗證](docs/UI-MASAFONT-SCROLL02.md)。

`game/assets/current/heroes/` 包含六人的現行走跑、跳躍、反應與肖像；新版攻擊在 `game/assets/v33/`，不以舊攻擊圖作為缺檔備援。敵軍、場景、武器與音訊仍使用其有效登錄版本。本機封存與生成用核准來源不隨試玩包配送；Git 歷史可追溯原始資源。

全員輕手三段前踏已加長；信長蓄力旋斬與空重範圍增加 50%，家康蓄滿重手可拔刀前衝一閃。刀劍、槍、錫杖／長棍與弓箭依實際裝備及命中事件配音；信長聲線與第二關三名武將出場白已修正，詳見 [音效紀錄](docs/AUDIO-V38.md)。

驗證與打包（Python 3、Node.js；Godot 放在 `tools/godot-4.7.2/`）：

```powershell
node scripts/test-v19.mjs
powershell -ExecutionPolicy Bypass -File scripts/package-native.ps1
```

打包器按登錄清單選檔，缺少依賴立即中止；不複製整個專案。輸出為 `artifacts/current-v33/吞食戰國-v0.33-Windows.zip`，附 SHA-256 及 `runtime-manifest.json`。封存區、生成來源、快取、測試及歷史文件均排除。舊開發紀錄仍在 `docs/`，遊戲行為以現行試玩說明為準。

Clone 後可直接執行已登錄素材；美術與語音重建另需建置腳本註明的核准來源或本機模型。自動驗證涵蓋六人新版動作、存檔保留、網路資料格式、場景、雙人啟動與音效路由；不等於實體控制器、真人連線、音效試聽或正式 EXE 匯出驗收。

介面已統一為毛筆字、紙色墨字與朱紅焦點；日文草書標題搭配「SENGOKU CONQUEST」，關卡命令使用卷軸令旨，血條加上古意細框。搖桿可完整巡覽選單並使用題名字盤，細節與驗證指令見 [UI 整理紀錄](docs/UI-V34.md)。
