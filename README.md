# 吞食戰國

Godot 4.7.2 Windows 原生橫向動作遊戲，目前版本 **0.33.0**，整合至 v40 首頁、介面與音效素材。信長、阿市、秀吉、家康、顯如、忠勝六人可玩，既有角色存檔與收藏資料保留。

主攻擊操作為輕手、重手、抓技、跳、拾取。現行登錄為信長 16 招／224 格、阿市 17 招／124 格，人物、可換裝武器與特效分離。每段輕手獨立播放、前踏並回正，第三段擊飛；重手集滿放開施放。詳細操作見 [試玩說明](README-試玩.md)，原 v33 素材基準見 [COMBAT-V33](docs/COMBAT-V33.md)，目前接入範圍以[現況盤點](docs/PROJECT-STATUS-20261022.md)為準。

前五關「桶狹間竹林」、「大高兵糧道」、「今川本陣」、「三河歸途」及「三河一向一揆」可玩，支援同機雙人、裝備耐久、玩家分檔倉庫、護符、成就及退出保存。啟動 `啟動戰鬥原型.cmd`，或直接開啟 `game/project.godot`，依通關進度解鎖下一關；第三、五關另有隔離進度的試玩捷徑。第五關整合見 [整合紀錄](docs/STAGE05-INTEGRATION-20261018.md)。

第 7–10 關「美濃山道」、「岐阜城門」、「上洛街道」、「金崎退卻」已接入，每關 5 場景／10 節點，小王位於第 6 節點、大王位於第 10 節點，合計 8 名將領與 24 招。新挑戰分別為落石破柵、破城門與箭雨安全路線、三組民眾護送與雙向火線、限時殿後與全隊撤離；四關採不同的 PeriTune 和風配樂，來源見[人物與配樂考據](docs/stages07-10-history-music.md)。八王的走路與三招各有 8 格，已完成原生動作及場景檢查；試玩內容見[新四關說明](docs/STAGES07-10-PLAYTEST.md)。

可用 [啟動第7至10關試玩.cmd](啟動第7至10關試玩.cmd) 獨立選擇四關，進度儲存在隔離目錄，保留正常戰役的解鎖規則。第 6 關由友軍開發、尚未接入，因此正常通關流程不跳過第 6 關直接解鎖第 7 關。第 11–24 關仍為候選；既定 24 關主題與大王配置保留。

2026-10-22 已更新[第一關與 24 關設計](docs/第一關與24關設計-v0.19.html)及[本機未完成作業清單](docs/PROJECT-STATUS-20261022.md)：第一關現為 7 場景／14 據點，固定單人 216／雙人 324 人。快捷進食為 Q／R1，格擋為 I／L2；工程頁可設定四類掉落機率。阿市第三段輕手已接入 B 版側踢。

介面已整理為古文書風格，使用隨附的繁中毛筆字型、日文草書標題與英文副標；選單支援搖桿換欄、清單退出、說明捲動及姓名／IP 畫面字盤。操作與中文輸入方式見[試玩說明](README-試玩.md)，UI 驗證入口見 [UI-V34](docs/UI-V34.md)。

`game/assets/current/heroes/` 包含六人的現行走跑、跳躍、反應與肖像；新版攻擊在 `game/assets/v33/`，不以舊攻擊圖作為缺檔備援。敵軍、場景、武器與音訊仍使用其有效登錄版本。本機封存與生成用核准來源不隨試玩包配送；Git 歷史可追溯原始資源。

全員輕手三段前踏已加長；信長蓄力旋斬與空重範圍增加 50%，家康蓄滿重手可拔刀前衝一閃。刀劍、槍、錫杖／長棍與弓箭依實際裝備及命中事件配音；信長聲線與第二關三名武將出場白已修正，詳見 [音效紀錄](docs/AUDIO-V38.md)。

首頁採 Amenoshita 前奏接循環曲，各頁使用原版 MasaFont Regular 與紅錦卷軸。新版刀劍、棍杖、薙刀、弓箭、飛針、敵我火槍、抓摔與蓄力聲已接入實際動作；來源、保留音檔與測試見 [v40 接入紀錄](docs/AUDIO-UI-V40.md)。除阿市外，跳重已加入大範圍擊倒劍氣；秀吉蓄力的特效與範圍加倍，見 [v39 戰鬥修正](docs/COMBAT-V39.md)。

驗證與打包（Python 3、Node.js；Godot 放在 `tools/godot-4.7.2/`）：

```powershell
node scripts/test-v19.mjs
powershell -ExecutionPolicy Bypass -File scripts/package-native.ps1
```

打包器按登錄清單選檔，缺少依賴立即中止；不複製整個專案。輸出為 `artifacts/current-v33/吞食戰國-v0.33-Windows.zip`，附 SHA-256 及 `runtime-manifest.json`。封存區、生成來源、快取、測試及歷史文件均排除。舊開發紀錄仍在 `docs/`，遊戲行為以現行試玩說明為準。

Clone 不包含依既有交付規則僅限本機保存的第四關 Battle10 配樂與十段敵兵死亡語音；取得方式見[本機作業清單](docs/PROJECT-STATUS-20261022.md)。打包腳本已補死亡語音與第 7–10 關資產清單；3,461 檔原始資源閉包、全檔 SHA 與乾淨目錄啟動已通過。美術與語音重建另需建置腳本註明的核准來源或本機模型。

第 7–10 關的核心輸入測試已完成單人／雙人共 8 次、80 個節點，音樂檢查 38／38 與原有音樂回歸 148／148 通過。輸入測試有生命與無敵保護，證明路徑可推進，不代表真人難度驗收；另通過 98 張原生遊戲畫面、逐格動畫、25 項流程／存檔隔離、同機 ENet 雙程序 20 場景及乾淨包資源檢查；真人手感、難度與人耳混音待驗收。既有自動驗證亦不能代替實體控制器、兩台電腦連線、音效試聽或正式 EXE 匯出驗收。

介面已統一為毛筆字、紙色墨字與朱紅焦點；日文草書標題搭配「SENGOKU CONQUEST」，關卡命令使用卷軸令旨，血條加上古意細框。搖桿可完整巡覽選單並使用題名字盤，細節與驗證指令見 [UI 整理紀錄](docs/UI-V34.md)。
