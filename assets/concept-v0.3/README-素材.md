## 如何評論

在企劃網站「素材草案」區留言，例如：

- 信長 03 重擊：刀弧可以再厚，收勢更低。
- 阿市 02 輕擊：針的辨識度不夠，衣袖遮住手。
- 布景／雨夜：地面太亮，路人應更靠後。

請先定人物輪廓、衣甲配色、招式出力與場景密度，再進入完整逐格動畫與引擎材質製作。此包不更換已交付 M1 的程式或暫代素材。
