## 檢查與導入注意

真實透明通道已讀取驗證：信長 1,026,357 個 alpha=0 像素；阿市 1,034,999 個 alpha=0 像素；兩張主體最高 alpha=254。所有 18 格在 alpha>32 的可見主體／特效範圍均未接觸切格邊界，人物、武器與士兵目視完整。

極低 alpha 柔光仍可能到达格邊，因此單純以任何 alpha>0 的 get_used_rect 取框可能含多餘透明邊；可見邊界數據在 alpha-qa.json。第 8 格整組已縮小以保留完整特效，其人物比例及脚底需由 renderer 單獨校準；其他格脚底也不是同一像素位置。第 5 格保留跳躍離地姿勢。
