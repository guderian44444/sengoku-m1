# 秀吉新版素材交接

本包依新版 16 招製作。以 review_manifest.json 指向的版本為準，舊單手、90% 頭部與舊重手版本不可拿來覆蓋新版。

## 人物與比例
- 採已核准的深藍紅襟、黑金甲、灰褲、腰前金葫蘆扇外觀。
- 全套頭部由原始 100% 局部縮為 95%，頸接點固定；不是把整個人縮小。
- 刀招雙手同握刀柄；抓取時收刀。
- 葫蘆扇固定收納，不參與主武器替換。
- 一般預覽站立約 150 px。空中招增加上方留白，不縮小人物，地板比一般預覽下移 80 px。
- 抓摔同時提供原始分層精度與統一遊戲預覽，整合時使用 metadata 的 normalization，不用每張 bounding box 自動縮滿畫布。

## 圖層與播放
- body/body_canvas 為真 RGBA；weapon 為獨立圖層；composite 是預覽合成。
- GIF 只供審閱，不能拿有灰背景的 GIF 當遊戲角色透明貼圖。
- 按 metadata 每格 duration_ms 播放，不以 GIF 檔總大小或固定 fps 推算。
- 攻擊事件用指定事件格觸發，不從刀光亮度推測。
- 抓摔對手獨立，手部接點、釋放與落地事件均在 metadata。
- 統一腳底與世界原點，不對每張圖重新居中；空中位移保留。

## 目前限制
- 人物是完整姿勢畫格，不是可任意換角度的骨架。
- 武器支援獨立替換與角度/握持點；現在平面刀圖未包括所有透視造型，極端側轉仍需按武器種類提供透視替圖。
- 每招已做逐幀圖像、透明與 GIF 解碼/時長檢查；不把解碼當作已在正式遊戲正常播放驗收。
- 未變更 Git、遊戲 runtime、招式傷害或判定程式。數值意圖是交接說明，需遊戲端接入並測試。

## 重建
Python scripts/build.py 產出一般輕攻擊、空中與衝刺。
scripts/build_heavy_step.py 產出最新前跨、翻刃向上重手。
原始生成圖與 head_scale.py 保留，便於還原比例。
其他專用腳本隨素材一併提供。

### 最新重建順序
先保留 reference/shared_ready，再依專用腳本重建：
1. build.py 可重建 light_2 與 dash_heavy；其中 light_1/3/air 的內建8格配置只是基礎。
2. build_light1_10.py：第一段10格700ms。
3. build_light3_step.py：第三段11格680ms。
4. build_air11.py：兩空中招11格（620/700ms）。
5. build_heavy12.py：重手12格950ms。
6. build_charge.py：蓄力準備/保持；build_charge_pivot.py：最新支點兩圈釋放17格1240ms。
7. 抓摔使用 grabs 內 build 與 normalization 腳本；以最新無瓶來源為準。
8. write_review.py 重產招式文件；package_current.py 依 manifest 打包。

舊基礎腳本不能最後再整批執行，否則會把專用11/12格版本退回8/10格。交接時先讀 manifest 的 revision 與資料夾，而非只猜檔名。

## 尺寸最終微調
使用者已接受動作方向，這輪不重生動作。light1 第4/8格先前校準與足點修復保留；light2 中段2–2.5%、dash中段2%、heavy兩個補姿勢格2.5%的小幅固有尺寸校準，依同向頭胸比較，不按整體外框等高。刀長保持固定，握點隨角色校正。light3 和蓄力段校準見 scale_audit 報告。所有源圖保留，可用 scripts 重建；最後微調需在原動作生成腳本後依序執行相應校準腳本。
