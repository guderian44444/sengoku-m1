# 秀吉攻擊畫面要素

主武為打刀，普通重手是低位收刀後往上揮，打飛前方敵人。按[共通規格](../README.md)拆成人物、刀與鞘、效果；葫蘆扇在這套主武招式中保持收納。

## 身份與動作風格

以[現有站立身份圖](../../../game/assets/v27/hideyoshi/body/idle/01.png)與[固定尺規說明](../../../game/assets/v27/hideyoshi/revisions/v32/README.md)為準。保留束髮、臉與鬍鬚、藍紅外衣、黑金甲、灰褲、膝繩、鞋與金色葫蘆扇配件。舊短槍來源不作本次主武參考。動作較快、近身緊湊、轉髖靈活；不縮短人物腿或把臉改成年輕女性。

## 普通重手關鍵畫面

低位收刀、馬步下沉、由腰肩帶動上揮、前方接觸、上揮隨動、雙腳站穩六個畫面都要可讀。低位預備是持刀姿勢，不自行改成拔刀穿身；秀吉不是家康的突刺模板。

## 分件與握點

頭、束髮、軀幹甲、外衣前後片、上下臂、手、褲腿、鞋、收納葫蘆扇分開。站立等效尺規沿用現有登錄，六格共用同段比例；蹲身不縮成小人。雙手持刀時保留既有同一柄軸與正確握次，空出手做抓技時需有武器收納交接。

## 本角色檢查

沒有回退短槍；普通重手為低位上揮；三次輕手各有一步；滿蓄確實兩圈而非一步三連斬；葫蘆扇不自行參與新攻擊；腳底、臉部尺規與雙手軸一致。詳見[武器](../weapons.md)與[效果](../effects.md)。
