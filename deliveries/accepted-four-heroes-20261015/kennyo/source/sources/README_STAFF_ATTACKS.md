# 顯如 03｜輕手三段與普通重手

使用已核准的 03 號身份：白頭巾、瘦長智將、頸部大念珠、深色僧衣與局部黑甲。現階段常規預覽持飾頭錫杖；人物層不含可替換武器。

## 交付範圍
- `light_1`：後腳抬起墊步、左向橫揮、收回共同預備姿勢；7 關鍵幀，670 ms。
- `light_2`：重新後腳墊步、反向右揮、收回共同預備姿勢；7 關鍵幀，680 ms。
- `light_3`：第三次墊步，正面、左側、背三分之四、背面、右側的完整一圈；11 關鍵幀，950 ms。水平旋轉相位記錄 0 至 360°，背側武器另層。
- `heavy`：近身低位收杖、一次前腳邁步、向上重打、高位隨動、完整收招；8 關鍵幀，1100 ms。

動畫時間是供檢視的製作節奏，未指定傷害、攻速、碰撞框、霸體或不可中斷規則。三段輕手是三個獨立動作，不會因一次按鍵自動連播。

## 每招檔案
- `source.png` 與修正版 source：imagegen 產生的透明原始姿勢圖，保留原檔。
- `prompt.txt` 與修正版 prompt：實際生成提示。
- `body_XX.png`：人物裁切。裁切會依連通輪廓排除相鄰格碎片，保留原始透明邊緣。
- `body_canvas_XX.png`：按固定尺規與腳點放置的人物層。
- `weapon_XX.png`、`weapon_front_XX.png`、`weapon_back_XX.png`：完整獨立錫杖層及前後遮擋。
- `hand_occlusion_XX.png`：由實際握持手指像素提取的緊貼遮擋片，沒有整段手臂覆蓋武器。
- `effect_XX.png`：獨立踏步塵；空揮預覽不播放命中爆點。
- `composite_XX.png`：真透明合成。
- `normal.gif`、`slow.gif`：遊戲等效尺寸、正常速度及三倍慢速。
- `body_only.gif`：純人物動作檢查。
- `contact.png`：全部關鍵幀接觸表，並非敵人受擊演示。
- `metadata.json`：來源雜湊、裁切、固定來源尺度、根點、腳點、握點、層次、角度、旋轉相位與事件。

## 尺規與位移
所有 1536×1024 來源共用單一 0.337 倍尺規；1254×1254 的 light_3 來源共用單一 0.406 倍尺規。以共同預備姿勢為站立約 163 px 的基準，不按各格人物外框高度單獨縮放。蹲身、抬腳與轉身自然改變畫面高度。

輕手三段使用完全相同的起手與最終預備姿勢、握點和杖角。最後保留本段向前根點位移：16、16、18 px。連段接入時，以前段保留後的世界根點作下一段原點；受阻擋時可停止世界根點前移，人物仍完成其轉腰揮擊。腳點以實際草鞋承重點量測，並非依透明外框置底。

## 武器與效果
`weapons/` 含共用長棍、飾頭錫杖、薙刀，可獨立替換。預覽使用 215 px 完整飾頭錫杖，主握點為武器畫布 `(64,178)`。第二手按實際空握點落在同一桿軸；被遮住的副手不捏造正式座標。水平旋轉的部分側向階段使用明記的軸向投影，真實武器長度仍保持 215 px。

`fx_neutral/` 含獨立透明三格踏塵、三格中性鈍擊接觸。鈍擊只在已確認碰到目標時啟用，不添加治療、召喚、法陣、元素傷害或額外狀態。

## 製作與接入界線
人物新姿勢及效果使用內建 imagegen。後處理只有裁切、透明輪廓分離、單一尺度縮放、武器按握點變換、手指遮擋及 GIF 時序合成。沒有 Comfy、Qwen、光流或以平移一張人物冒充整段步態。

本包是可檢視及接入準備用分層素材，沒有修改 Git、runtime 或網站。真正敵人的擊退／擊飛動畫及碰撞事件由後續接入負責。當副手或肢段被原畫遮住時，metadata 明確標為遮擋，沒有宣稱已製作完整可重綁的人形骨架。
