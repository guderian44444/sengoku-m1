## 不可混淆的動作

輕手為左揮、右揮、第三段一圈；普通重手是收杖後前進一步，由下往上重打並較高擊飛，不需滿蓄。滿蓄另為頭頂高舉、單手換握尾端、水平完整兩圈。空中輕手揮杖、空中重手下砸馬步落地。抓中兩次頭槌，第三次前拋，反向輸入過肩反摔。衝刺重手是前揮。

人物、完整長柄武器、效果及受害者分層；按實際動作長度決定影格數，不強制六格或12格。原文中的「普通重手六節點」是關鍵姿勢順序，不是只能交六張播放格。效果依事件觸發，不因法器外觀新增治療、召喚或魔法傷害。
