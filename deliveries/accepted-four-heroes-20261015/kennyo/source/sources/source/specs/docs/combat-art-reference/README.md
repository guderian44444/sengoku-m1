## 已確認操作與命中效果

| 操作 | 已確認規則 | 人物畫面必須交代 |
| --- | --- | --- |
| 輕手三連段 | 每段重新按；每段向前推進，可用後腳向前墊半步；前兩段推人、不穿身；第三段擊飛 | 三次獨立踏步、身體發力、連段交接。碰到推不動的目標，根點位移可停止，手臂仍可完成揮擊 |
| 普通重手 | 每角色固定一招；時間較長，可被敵人攻擊中斷 | 預備、發力、接觸、收招。需要受擊出口，不預設霸體或無敵 |
| 重手長按 | 集滿後保持準備；放開施放大範圍招 | 進入集氣、可停留的滿蓄姿勢、施放、完整收招 |
| 阿市滿蓄放開 | 一般為擊退穿透箭；上方向加放開為箭雨 | 向前射與朝天射分開；朝天射前有蹲下、抬弓的姿勢交接 |
| 抓技 R2／RT | 抓住後輕手打兩次，第三次丟出；搖桿反向直接過肩摔 | 抓住接點、保持、兩次接觸、正向拋出、反向過肩釋放 |
| 跳起加輕手 | 全員用主武近距離揮打，攻擊力與範圍各加 20% | 確實離地、武器揮打；弓不射箭、槍不改成普通直刺 |
| 跳起加重手 | 刀槍棍：跳起、舉武器、下揮、馬步重落地，接觸者擊倒；攻擊力與範圍各加 30% | 上升與下降方向、完整下揮、雙腳承重及武器接觸方向 |
| 阿市空中重手 | 前下方直射三箭，擊退，射程半個畫面寬 | 拉弓接放弦；三箭不應畫成射向三種方向的扇形箭 |
| 跑步加重手 | 武器前揮，擊飛一般敵人；大小王有機會格擋；盾兵只受一般命中 | 跑步銜接、前揮接觸、減速收招；不進入蓄力 |

擊退是站立向後移動；擊倒是倒地；擊飛是離地拋出再落地。20% 與 30% 是同角色、同武器地面招式的判定倍率，不放大人物或武器 PNG 來代替。阿市空中三箭未指定額外倍率。

輕手三段是有前置條件的連段：第一段可以單獨使用；第二段只能在第一段後追加輕手，第三段只能在前兩段後追加輕手。每一段都必須包含完整回正動作，以同一套預備姿勢結束，連段停在第一或第二段時也能自然回正。第二段的第 1 幀完整承接第一段回正後的最終幀，第三段同樣承接第二段回正後的最終幀；人物、握點、刀的角度／刃向、尺規與色彩均須連續。回正不把根點往後退，前踏位移保留；每段仍由追加按鍵啟動，不在一次按鍵後自動播完三段。

腳步優先做出後腳抬起、向前落下與重心移動；使用者已允許後腳墊半步，不強制每段左右腿完整交換。前腳支撐時保持實際世界接地點，不能只平移整張人物或只移動背景來冒充踏步。信長的整套試作見[素材入口](../../prototypes/nobunaga-combat-set-v1/README.md)。

## 三層素材的責任

| 層 | 包含 | 製作要求 |
| --- | --- | --- |
| 人物 | 頭臉、身體、衣甲、頭髮、手指、腳、腰帶等固定配件 | 不烘焙可替換武器、刀柄、刀鞘、弓、弦、箭、刀光、劍氣或地面塵。保留空握與拉弦手勢 |
| 武器 | 刀與鞘、槍、棍杖杵、弓身、弓弦、箭與投射物 | 依人物握點、武器支點與前後關係合成；弓弦與箭的移動不屬於人物貼圖 |
| 效果 | 命中光點、短刀弧、劍氣、蓄力提示、箭尾、落地塵等 | 由發力、放箭、接觸、落地事件觸發；不決定角色大小，也不代替敵人的受傷／倒地動作 |

背景、地面、光暈與投影不放進人物透明圖；投影在合成時按腳點／離地高度繪製。貼身念珠、披風屬人物，參與抓摔或收納的獨立法器／葫蘆扇可另做配件層。

合成順序依每格遮擋切換：後方效果與武器 → 後方人物部件 → 身體 → 前方武器 → 手指遮擋片 → 前方效果。抓摔時，受害者是第二個人物，不畫死在施術者貼圖中。

接觸預覽使用獨立敵人或量測替身。需要下列狀態來確認攻擊畫面，不把敵人畫入主角來源：

| 反應 | 預覽需要的敵人畫面 |
| --- | --- |
| 前兩段輕手推人／箭擊退 | 敵人仍站立，向後移動；與主角保持接觸距離，主角不穿身 |
| 第三段／上揮／旋圈擊飛 | 接觸、離地、拋物飛行、落地各可辨識，不只有站姿旋轉 |
| 長槍抽回／落斬／箭雨擊倒 | 接觸與跌倒、伏地／躺地分開；長槍等抽回才進入倒地 |
| 被抓住與投摔 | 被拉近、頭槌／膝擊受傷、肩上翻轉、鬆手後獨立飛出與落地 |
| 王格擋／盾兵普通命中 | 兩種反應分開；盾兵不因跑步重手而被畫成擊飛 |

## 共用動作索引與關鍵畫面

索引只供本組製作清單使用。六人都覆蓋下列 16 項；阿市另加 `charge_rain`。可共用骨架或圖，不代表要獨立生成 16 套完整人物。

| 索引 | 必須看得到的關鍵畫面 |
| --- | --- |
| `light_1` | 預備、第一步著地、第一擊接觸、可接第二段的結尾 |
| `light_2` | 承接第一段、第二步、第二擊接觸、第三段預備 |
| `light_3` | 第三步、最大揮幅、擊飛接觸、隨動、回到可移動姿勢 |
| `heavy` | 明確預備、較長發力、武器接觸或放箭、完整收招 |
| `charge_ready` | 從待機進入集氣姿勢，手腳穩定 |
| `charge_hold` | 滿蓄姿勢可停留；細小呼吸／衣髮跟隨，不增加位移 |
| `charge_release` | 從滿蓄姿勢出發，旋轉或射箭，最後收招 |
| `air_light` | 離地、近身揮打接觸、隨動、可回到下降／落地姿勢 |
| `air_heavy` | 上升預備、舉武器、下降下揮、接觸、馬步著地；阿市改三箭放弦 |
| `grab_start` | 伸手、抓住實際衣領／上臂接點、將對方拉近 |
| `grab_hold` | 穩定抓住；重心與相對距離可停留 |
| `grab_hit_1` | 保持抓取接點、頭槌／膝擊接觸、回到保持 |
| `grab_hit_2` | 再次發力、第二次接觸、預備拋出 |
| `throw_forward` | 拉近／轉髖、拋出、明確鬆手、施術者收招 |
| `throw_reverse` | 反向轉身、將受害者拉上肩、過肩翻出、釋放、站穩 |
| `dash_heavy` | 跑步末步、前揮接觸、減速支撐、回到站姿 |

六格作為一段招式的常用關鍵姿勢交付，依序為準備、預備發力、動作中、接觸／釋放、隨動、收招；抓摔、旋轉等以實際事件拆分。當六格無法表達動作，不硬塞或以重複站姿充數。

輕手的 `light_1`、`light_2`、`light_3` 是三套獨立動畫，各有自己的多張不同姿勢、前踏、命中與收招；按第一下只播放第一段，後續輸入才在連段窗口依序接第二、第三段。不能把三擊合成一套按一次便全部播放的動畫。各段張數依動作長度與可讀性調整，不強制 12 張；第三段仍為擊飛。

信長普通重手最初用 12 張完整動作，後續依使用者要求補間與加幀。整套版採 25 張，含高舉預備停留、下斬發波與回正；其餘招式同樣按動作長度調整，不固定 12 張。

旋轉兩圈須記錄連續轉向與前後遮擋。可以重用一圈的骨架／視角姿勢兩次，但相位要累積 720°，不能把首尾角度直接插值成零圈，也不能只有一圈就收招。揮擊的蓄力、出手、隨動速度分開設定，不要求六格等時播放。

## 畫面與登錄資料

鏡頭採固定右向側面／四分之三視角，與既有遊戲人物一致。除真實招式轉身外，不每格更換鏡頭。統一站立等效人體尺規；蹲身、馬步、跳躍、倒地不以當格外框高度縮放。保留頭身比、腿長與衣甲體積。

目光跟隨接觸方向；預備與滿蓄保持專注，第三段、重擊、投摔釋放有短促發力表情，收招恢復。臉型不隨表情改變；忠勝的面具／兜保持遮擋，不憑空露出另一張臉。衣髮、念珠、裙片與披風在發力後有短暫隨動，不能每格改長度或穿過四肢。

優先輸出獨立 PNG，或使用受控同尺寸圖格。若合成六格來源，採三列兩行，每格有透明安全邊界、完整人物與一致尺度，不能讓手腳跨到鄰格。原生尺寸按身份基準與用途確定，裁切和量測依實際輸出；不能把不存在的像素尺寸或握點當成已完成資料。

| 每格資料 | 記錄內容 |
| --- | --- |
| 圖源與裁切 | 來源檔、SHA256、明確裁切矩形；PNG 真透明、完整輪廓、與相鄰圖不混入 |
| 站立尺規 | `body_height` 與量測依據；頭部／身體比例不能靠特效大小校準 |
| 根點與腳 | `foot`／根點、左右腳支撐、空中虛擬根點、前踏或前突位移 |
| 手與接點 | 左右手、主握點、輔助握點、抓人接點；阿市另記實際拉弦手指接點 |
| 武器方向 | `weapon_angle`、前／後層、可見狀態；刀鞘口與抽刀進度、旋轉相位另記 |
| 手部遮擋 | 手指覆在刀柄／槍桿／弓柄前的緊貼遮擋片，避免整條手臂覆蓋武器 |
| 事件 | 腳落地、揮擊接觸、抽回、箭離弦、箭出畫面、投摔釋放、落地等 |

目前弓人物的 `second_hand` 用來控制弓弦，不要拿它表示雙手握刀／槍／棍。非弓的左右手可按現有資料記為 `right_hand`／`left_hand`；對應 renderer 的正式欄位於接入時確認。現有 `weapon_angle` 為武器朝上 0°、順時針正值、右向基準；空間水平旋轉要另記相位與視角，不能誤當成畫面平面轉角。

## 生圖與骨架製作順序

1. 先鎖人物身份、站立尺規、鏡頭、配色；顯如先產生一張身份／服裝候選並確認，再做整套攻擊。
2. 若採骨架，先準備頭、後髮、軀幹、上／下臂、手、骨盆、上／下腿、腳、披風／裙片。補齊關節後方被遮住的部位，足掌獨立以避免小腿轉動帶著鞋底翹起。
3. 先用簡單武器導引線擺關鍵姿勢與量測握點；人物輸出不含導引線。中間動作用骨架補間，轉身、手指、膝肘或衣甲形變不佳時補畫。
4. 再製作可替換武器及必要角度，確認握持、完整長度與前後遮擋。
5. 使用獨立效果合成。先測空人物、空武器、無效果的組合，再加入接觸效果。
6. 檢查一把基準武器與一把同類較長武器、左右向、完整動作；通過再批量做其他武器。

阿市[骨架拉弓試作](../../prototypes/oichi-bow-rig-v1/README.md)可參考分件、腕與手指握點分開的做法；其接縫與固定弓形仍是試作限制，不是正式品質標準。

## 提示詞框架

每次生圖只選一層、一角色、一動作或一套分件，避免把人物、武器、命中效果綁成整張圖片。

```text
用途：吞食戰國的可分層 2D 攻擊素材。
人物：<角色名>，身份圖 <已確認參考圖>；保留臉、髮型、衣甲與配色。
本次層：人物／武器／效果，僅輸出所選一層。
動作：<角色文件中的一列>；關鍵畫面按既定順序。
鏡頭：固定右向側面／四分之三；同一人體尺度與完整腳底基準。
人物層：空握／拉弦手勢，不畫可替換武器、刀柄、鞘、弦、箭或效果。
武器層：完整武器與握點，無人、手、背景、光軌；弓身不烘焙弦或箭。
效果層：獨立透明效果，無人物、武器或地面背景。
輸出：真透明 RGBA；完整頭髮、手指、腳與配件；每格周圍留透明安全邊界。
避免：身份飄移、姿勢僅靠整圖旋轉、裁斷輪廓、假棋盤背景、文字、不同格比例跳動。
```

欄位只填實際量測；還沒有圖的座標保留待量測，不用示意數字當正式握點。

## 驗收與待確認

依最新確認，優先檢查每張關鍵圖的人物外觀、站立等效尺寸、配色是否一致，以及武器角度與真實握持點。補間影格的小模糊／疊影，需在實際遊戲縮小尺寸、正常速度及連續播放下判斷；放大暫停的中間張不單獨作為否決依據。關鍵張不應靠模糊或特效掩蓋身份變化；武器握點錯位仍須修正。

| 檢查 | 接受條件 |
| --- | --- |
| 人物動作 | 關鍵張外觀、人體尺規與配色一致；腰肩肘腕與腳步共同發力；高速補間依實際遊戲尺寸檢視 |
| 輕手前踏 | 三段各有獨立一步；根點能在敵人阻擋時停止，不在圖片中固定穿身 |
| 握持 | 武器角度與主握點匹配；副手沿同一柄／桿軸線，間距穩定；弓的拉弦手與弦中點一致 |
| 武器分層 | 換同類武器後不殘留另一刀柄／箭／刀光；刀鞘與武器能獨立遮擋 |
| 旋轉 | 刀在腰部、槍棍在頭頂的水平旋轉各兩圈；後方武器不錯蓋臉或軀幹 |
| 空中重手 | 實際上升、舉武器、下降、接觸、馬步落地；20%／30% 不靠人物變大 |
| 抓摔 | 施術者與受害者接點同步；鬆手後敵人獨立飛行；反向摔方向正確 |
| 效果 | 發力、接觸、放箭、落地按事件；沒有打中時不播放命中火花／敵人反應 |

待確認集中如下：未滿蓄放開的行為；蓄力／滿蓄等待是否可中斷；大小王的抓摔、擊飛與擊倒抗性；家康突刺是否附帶擊倒；阿市普通箭與空中三箭是否可穿透；兩圈旋轉與箭雨同一敵人的命中次數；傷害、距離、蓄力秒數與接續窗口；顯如最終臉、體型、僧衣及主武外觀。這些不阻止準備姿勢，卻不能由生圖自行決定。

目前棍類與顯如無正式 runtime 註冊；替換光秀時，角色存檔、裝備、語音、選角與招式 ID 的遷移另做，不用改名覆蓋舊資料。
