# 忠勝攻擊畫面要素

主武為長槍。普通重手長刺穿透多人，抽槍時使刺中者倒地。按[共通規格](../README.md)分離人物、完整長槍、效果。

## 身份與動作風格

以[現有站立來源](../../../game/assets/v22/tadakatsu/idle.png)及同資料夾登錄為準。保留黑金甲、鹿角兜／面部護具、胸前念珠、紅色繫帶、黑羽披風與人物比例。雙手長槍軸要穩、槍桿長、槍刃窄；不把鹿角裁掉或變小，不用大光圈掩蓋槍尖與手。

## 長刺重手關鍵畫面

1. 雙手收槍，槍尾與後手仍完整，雙腳穩。
2. 較長預備，前方刺擊軸明確。
3. 肩腰推槍，雙手沿同一桿軸，前手可受控滑移。
4. 槍尖完成長距離穿刺，多名受害者的接觸事件獨立。
5. 沿原軸抽槍；此時刺中者倒地，不能都在刺出前倒地。
6. 回到可移動／續招姿勢，槍長、刃寬不變。

## 分件與握點

鹿角兜與頭、胸甲、念珠前後段、肩甲、上下臂、左右手、骨盆甲片、腿、腳、羽披風分開。雙手握槍量測主／輔接點；滿蓄單手尾握另有接點。長槍與鹿角兜的透視前後關系逐格檢查，不把雙手上移誤畫成槍桿變短。

## 本角色檢查

長桿窄刃比例正確；輕手刺刺橫掃、三次前踏；普通重手抽回才倒地；滿蓄頭頂兩圈；空中輕手揮打；抓技不用舊插槍肉盾；槍與鹿角／身體不穿模。詳見[武器](../weapons.md)與[效果](../effects.md)。
