# 第三關實際程式參照

查閱日期：2026-10-18 UTC。來源為 GitHub main，逐檔blob SHA列於source_file_hashes.json。以下是讀程式得出的配置與行為，未在本次啟動引擎重新實測。第四關新版另屬未實裝設計。

- 雨營警鐘：初始／維持人口單人6、雙人9。盾槍、槍兵、弓兵順序循環，單人各2，雙人各3。死後240tick補1，放行間隔45tick。拆掉兩支警鐘柱後取消待補，清殘兵才完成。
- 重重木障：沒有敵兵；拆3道木障，HP180／210／240。
- 本陣防線：6／9人。單人盾槍3、槍2、弓1；雙人盾槍3、槍3、弓3。前排空90tick後由後排補位，補兵延遲240tick、放行45tick。所有玩家活著、落地並抵達x2350即可完成，無須殺盡。
- 今川大帳：兩小王另加4／6雜兵。單人槍2盾槍1弓1；雙人各2。雜兵持續補，兩小王打敗後90tick義元進場，補兵繼續。義元敗退直接勝利，不要求清殘兵。
- 第三關上述補兵為目標驅動、無固定總出兵數；人口6不是整段總共6。48是含玩家／屍體的fighters陣列技術保護，不是同場敵軍數。
- 兵種不是亂數加權抽選：警鐘／帳內依kinds輪巡，陣線依slot表。物理weight則boss=heavy，普通敵=light；不應拿這覆蓋第四關獨立盾牌規則。
- 槍兵基礎HP65、弓52、盾槍90；雙人HP再乘1.35及難度。雙將HP260／240同規則。難度easy敵HP×0.75/傷害×0.65；normal1/1；hard1.35/1.3。
- 泛用波次雙人雜兵+50%的_scaled_wave不再套第三關專用目標分支。本次第四關按使用者每波6–8的要求也不再加人數倍率。
- project.godot物理60Hz，所以240tick=4秒，45tick=.75秒，90tick=1.5秒。
