# 第四關 三河歸途：素材與設定交接

本包是素材、動畫時間與關卡設計交接；不是已接入遊戲、已跑通關或已驗證難度的版本。先讀根目錄 manifest.json，再讀 settings/、layout/stage4_nodes_proposal.json 與 audit/。原始製作版本保留在來源，不直接覆蓋。

## 唯一版本入口
- 長照：base 僅基本動作；slam 使用槍直立、槍尾向下的 v5 畫格＋v7 時間。單震1秒、三連震2.5秒，每次最後下砸20ms，命中/聲音/特效同點。
- 長照大迴旋：spin v3，15格、1.44秒，武器與原金色效果擴大50%，特效依握點、武器角度同步。不要改回程序線條。
- 長照隨身石：rock v2，從腰側取石，release=.8/2/3.2秒；彈速2040世界單位/秒，34/tick @60Hz。1100是射程，絕不能當速度。預覽像素不是世界單位。
- 吉良：specials v3，現存活弓兵原地服從命令，技能不得生人或瞬移。每波射出前跟隨玩家，出手鎖定；範圍1.5倍，無落點提示。護衛補兵管理與技能完全分開。
- 富永：既有動作＋specials向前貼地劍氣。
- 三種兵：base 攻擊/受擊；alert-v3 僅覆蓋 ready/walk。未採用三兵legacy對照版。
- 鐵炮：legacy-reskin-v1；走路6格沿舊關原動作，gun_shot/hurt/struggle/death依舊版定義。沒有另做reload/stun/recover時沿原遊戲狀態映射，不混入被否決的新步態。
- 旗：v5 idle/damaged=8格×120ms=.96秒；破壞仍v4的800ms。旗座、繫點固定。
- 拒馬/柵欄：v5左上到右下透視，各有完整/受損/破壞。近戰敵直接穿過，無翻越狀態；玩家受完整柵欄阻擋，砍破後通過。

## 接線規則
1. 不按每幀外框拉成同高。保留原畫布、root/pivot、source腳點和已定人物比例。打擊武器是敵兵固定配備，無替換武器需求。
2. 基本PNG/atlas保持原解析度，本次整理沒有重採樣。atlas裁格在原像素座標；源圖腳點轉local時先減source_rect左上角。
3. 劍氣、碎石、箭、槍口效果與人物分層；效果時序與事件表同步。角色不能被落地碎石大塊遮住。
4. 同一招同一目標去重，三連震每波各一次。重甲長照永不擊飛/擊倒，蓄力絕招只暈；大盾不可抓起或摔倒，抓技只短硬直/地面擊退。一般盾與大盾規則以settings/shield_combat_rules.json為準，不讀舊資料混合規則。
5. 音訊只載正式處理檔，避免把preview、raw、superseded當遊戲資源。木盾用dry-v7，不能用金屬武器格擋聲。
6. 關卡節點共有13段進軍，5區為3/2/3/2/3；位置/敵數/HP/傷害/冷卻明列為可調初值，不宣稱平衡已測。
7. 泥地玩家減速且不能起跳，敵人也減速；不藏蘆葦伏兵；旗和裝飾不作必殺清場條件。
8. 最終敗退使用現有頂部提示，不新增特殊文字覆蓋層。

## 外部依賴與驗收
音樂百折不撓為 SOURCE_REQUIRED：依 audio/music/external_dependency.json 與官方來源自行取得，再用附帶匯入腳本建立遊戲用loop。包內不含該完整或改作音訊。其餘歌曲署名/來源列於 audio/music/CREDITS.txt。
尚未跑遊戲引擎的圖片排序、碰撞、受擊、事件回呼、音量與難度測試。settings中的可調數值僅接線初值。所有未決項見 OPEN_ITEMS.json；不得以存在素材等同功能已實作。

## 營帳助陣補件
背景兵3種×4原生姿態，880ms循環，8名不同phase配置，替代原靜態助陣層。綁音訊時每次僅一組，至少2秒全域間隔；gain=0.65，速度=1.0。合成短呼聲技術解碼通過、尚未人工聽驗。營帳烘焙白旗未拆成動畫，獨立站旗沿用8格0.96秒。
