# 第四階段：軍帳背景助陣短呼聲

交付日期：2026-10-17。用途為軍帳後方的低音量助陣聲。包含 4 個單人男性合成聲線短呼聲、2 組已混好的立體聲群吼，以及完整生成與驗證紀錄。目前尚未接入遊戲 runtime。

## 播放與音量建議

建議直接採用 `groups/` 的其中一組，作為背景 one-shot。混音檔已包含每層 0.13–0.18 倍的低音量、錯開起音與左右聲像；不用再對整組套用一次這些分層倍率。單人檔已正規化至 peak 約 0.68，主要供重混使用，並非建議直接以全音量在背景播放。

兩組混音建議播放倍率先設為 **0.65（-3.74 dB）**，再於場景中視前景音量調整至約 0.4–0.85。0.65 倍時 WAV peak 約為 A -22.82 dBFS、B -21.09 dBFS。這是檔案音量之外的建議播放倍率，不代表已修改遊戲設定。

整合時建議走獨立的背景聲道，遵循既有 Voice 音量設定。每次事件只播放 A 或 B 一組，不要讓每名軍帳人物同時各播一整組；建議間隔至少約 2 秒。前景武將台詞播放時，可另降背景 3–6 dB。上述皆為待整合建議，目前未新增觸發事件、播放程式或音量匯流排。

## 製作與追溯

- 使用既有離線模型 `Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice`，revision `0c0e3051f131929182e2c023b9537f8b1c68adfe`；既有 CustomVoice 合成聲線，未使用真人參考錄音或聲音複製。
- 生成提示只要求短促「おおっ／うおっ」，不加台詞、招式名、長元音或長尾。7 次原始生成均保留於 `raw/`；4 次採用，3 次因處理後過長未採用。未採用內容不應直接當作最終素材。
- 每個 take 的文字、指令、seed、原始與候選檔雜湊及數據在 `takes/*.json`。`manifest.json` 列出最終採用檔、來源 take、每層聲像與起音。`settings.json` 記錄推論和處理參數；`generate_cheers.py` 為本次獨立生成腳本。
- 原始模型輸出 24 kHz。處理僅去除首尾低於 -46 dB 的靜音、70 Hz high-pass／6.2 kHz low-pass、轉 22.05 kHz、音量調整與立體聲疊合；未變速、未改音高、未加混響／延遲／延長尾音。左右聲像使用 equal-power pan。
- 原始資料、候選檔、模型權重均未混入既有遊戲語音目錄；此 ZIP 不包含模型權重。未執行舊生成器主程式，未安裝軟體或變更憑證。

## 驗證與限制

`verification.json` 記錄 **29 個音訊檔全部成功解碼、所有樣本有限、數位削波樣本數為 0**；WAV／OGG／MP3 均已檢查，兩組混音左右聲道確實不同。4 個單人檔長度皆介於 0.450–0.719 秒，兩組群吼皆短於 1.2 秒。

`existing-voices-before.json` 記錄本次生成前既有 604 個語音與登錄檔的 SHA-256；生成完成後逐一核對，604 個均未變動。未變更遊戲 runtime、既有語音登錄或 Git。`SHA256SUMS.txt` 提供本包各檔雜湊。

**未完成人工試聽或日文語音辨識。** 此環境不支援可靠音訊聆聽且無日文 ASR；目前只通過技術檢查。實際發聲是否完全符合無詞呼聲、是否有截音、助陣情緒與場景平衡，仍須人工聽過 `preview/` 與採用單人檔後確認。`human_listening_review` 與 `spoken_content_verified` 均明確保留為 `false`。
