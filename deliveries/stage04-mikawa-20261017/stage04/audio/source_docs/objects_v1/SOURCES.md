This package reuses the existing authorized CC0 source archive. Its original license was read locally during production on 2026-10-17. No third-party source download was added. Processed variants are newly edited game sound design, not an artist-approved or historically authenticated version. Original source samples are preserved. Filtered noise layers and sequencing are generated by build.py, with a fixed reproducible random seed. No oscillator-based boom was added.

The precise original source path(s), processing description, level target and event mapping for every output are in manifest.json. Derived edits and original generated layers in this package may also be reused under CC0 1.0. Attribution to Kenney is optional but retained voluntarily. Python tooling dependencies are not bundled.
