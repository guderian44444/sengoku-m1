## 固定規則與待調值
- 初始敵量直接來自靜態圖，不是已核准的遊戲難度；除吉良六護衛規則外皆可調、未實測。
- 無普通無限增援。吉良為唯一護衛維持節點，3秒補兵延遲是助手提案；不能由命令技能補兵或集合。
- 吉良敗退先停止並取消補兵，餘下最多六名弓兵可逐一清完，保證此後敵數有限。
- 普通旗／柵欄／拒馬都不列清場必殺物。可破壞資產已存在；HP與碰撞形狀未定。
- 玩家被柵欄擋住，需砍破才通；近戰敵直接穿。獨立玩家/敵兵碰撞mask；破壞時立即移除玩家阻擋。柵欄HP提案為3次基礎近戰命中，未實測。
- 泥地輪廓、0.65倍率與乾路60像素深度皆為可調提案。玩家已在空中時落入泥地的處理未定，不擅加強制落地。
- 長照平時不能被擊倒／擊飛，終戰劇情倒地是獨立終態，不與普通受擊規則混用。

## 真正缺口
1. 第7節點不建立NPC依賴：清橋頭守軍→解除封鎖→上方提示「橋頭封鎖解除，友軍可以通行。」。友軍通行是敘事，不要求新角色或護送系統；此為配置初值提案。
2. 圖為13張獨立視窗，非無縫長地圖；場景接縫、引擎單位、鏡頭限制、碰撞與導航尚未實作。
3. 鐵炮全部統一已核准Udono legacy換裝，吉良區域標鵜殿援軍；不另需Kira款，不使用遭否決rig步態。
4. 玩家柵欄通行已確定；物件HP/碰撞實際尺寸、泥地進入時空中狀態、補兵位置/延遲仍需調測。
5. 吉良箭雨+50%基準範圍需接回原特效/攻擊設定；此表不杜撰半徑。
6. 長照遠攻反制確定採隨身高速投石v2；接最終canonical素材/事件，不新增弓手。終戰用明確有限狀態：倒地0.6秒→起身0.7秒→從x1440以220px/s逃到x2250，達點發stage_complete一次；約4.982秒。時間/速度為可調提案，需接既有倒地起身逃離圖，未宣稱runtime已完成。
7. 營帳助陣兵已補3種×4格獨立真實姿態及透明循環/phase配置；非8格rig，未接引擎。沒有新增吆喝音效，只有可選事件。參見mikawa-cheering-animation-v1/animation_events.json。
