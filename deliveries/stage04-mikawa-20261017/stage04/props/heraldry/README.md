# 第四關・三河歸途｜旗印與家紋資產

## 內容
每家五組 SVG + PNG：直立幟旗 nobori、背旗 sashimono、甲冑布章 armor_patch、米白單色紋 crest_ivory、黑色單色紋 crest_black。
- 鵜殿長照與其直屬兵：丸に三つ石。圓環內三個正方形，上方一個、下方兩個。
- 吉良義昭與吉良所屬兵：丸に二つ引き。圓環內兩條相接的橫帶。
- 富永伴五郎忠元：本案使用吉良所屬標識；不主張這是富永個人家紋。
- 不以三巴紋替代鵜殿，不將吉良二引圖式自動套到第三關今川資產。今川既有旗印需另行核對，並非本包修改範圍。

## 美術設定與史料界線
家紋是傳統圖式的自繪幾何母版；所有應用使用同一組形狀。現代家紋目錄支持家族與紋樣的對應，但不等同證明具體武將在某次戰役中的實物配置。未找到足以斷言本包旗色、旗長、背旗或布章位置的當時實物史料，因此這些均為遊戲美術設定，不標示為歷史復原。來源中的商品或家紋圖片未複製到交付包。

鵜殿：墨藍 #222C39；吉良：暗朱 #743A3C；共用米白 #E8DFC8；少量舊黃銅 #AF9261。

## 使用
SVG 為母版；PNG 由 Inkscape 直接渲染，資產外部透明。紋樣 PNG 1024×1024；布章512×512；幟旗512×1280；背旗512×960。
請保留形狀比例，按需要對整個 SVG 等比縮放、換單色或整體透視變形。不要重新讓生成模型猜紋樣，也不要對背旗進行會改變內部圖式的局部重繪。角色預覽如未合成正確家紋，保留素色徽章區即可。

本包是獨立美術資產，不含遊戲程式、Git 或運行時變更。
