# v0.28 玩家、行囊與武器平衡

2026-10-13。本機 Godot 專案，接續 v0.27。

## 選單與人物

正式選角獨立成頁：左側顯示完整站姿、體力、基準攻擊、攻速、移動速度、範圍、擊退、投摔及護符效果；右側可切換護身符／武器，選一件裝備後立即更新數值與站姿武備。差值相對該人物的白板武器。阿市的基準列顯示普通弓射，其餘人物顯示第一段普通攻擊；數值為未扣敵方盔甲的實際傷害。金邊框、深色面板及標題重字保留街機風格，內文使用較輕的 Noto Serif TC 字重；使用既有合法附帶字型。

每位武將各有一把無附加能力的練習武器：信長練習打刀、阿市練習木弓、秀吉練習短槍、家康練習太刀、光秀練習刀、本多練習直槍。六件白板之外，保留原有 48 件收藏武器。蜻蛉切改為四階名槍，傷害 +9、範圍加成 +24、擊退 +3、火焰灼燒、攻速 94%、耐久 320；新人物不會自動得到蜻蛉切。

## 玩家與保存

主選單或選角右上可進入「玩家設定」。可建立 1–20 字的新玩家，兩名合作玩家必須選不同的存檔。玩家可以選同一位武將。每位玩家一份 `user://players/player-*.json`，內含各武將的總積分、永久生命加成、逐件行囊／耐久、裝備、金錢與解鎖成就；大關進度屬於該玩家。選擇的玩家另存於 `selection.cfg`。

第一次讀取舊 `characters-v1.json` 時，原 1P／2P 進度各轉入一個本機玩家，舊檔保留。正常保存沿用暫存檔、有效備份及未知版本保護。只保存有變更的玩家；物品出售／換裝先完成該玩家檔案寫入，再更新戰鬥中的裝備。寫入失敗保留原物品與金錢，離開遊戲前的保存失敗則取消離開。

再次出陣依然從大關起點、滿血三條命開始；不保存目前位置、波次、生命、剩餘命數或怒氣。行囊中的護身符與剩餘耐久現在會保存。工程訓練、素材展示與 IP 試戰不寫正式玩家進度。

## 行囊與出售

每位玩家、每位武將的行囊上限 120 件。同款武器可以持有多把，以不同編號與耐久區分。從選角「物品管理／出售」或暫停的裝備入口開啟：顯示物品原圖、能力、簡介、剩餘耐久和出售價格。出售需要確認，價格依剩餘耐久折算；裝備中的物品須先換下。購買入口暫時停用。

拾取較高階武器會立即換裝；同階或較低階武器入行囊。護身符在目前未裝備時自動裝上，其餘存入行囊。行囊滿時提示並保留地上物品。

## 耐久與護身符

武器有獨立設定的耐久。每次實際造成敵人傷害時，每人次扣 1，包含元素的持續傷害；空揮、被防住或無敵目標不扣。歸零立即刪除該件，優先換行囊中的可用武器；沒有備用時保留較弱的攻擊，傷害約 55%，可繼續拾取。已射出的箭與持續傷害記錄來源武器編號，後來換裝不會扣新武器耐久。

護身符取消周身光暈，頭上以小型半透明功能圖示表示 BUFF：三種吸收傷害護符共用盾牌，疾風為風線、武神為劍、月影為向外雙箭頭。圖示與目前姿勢的圖像上緣保留 14 像素空隙，跟隨跳躍，不遮住人物；卸下、損壞或死亡後消失。

## 掉寶與成就

30 種特殊表現解鎖後在戰鬥中顯示，並保存到該人物的成就帳。每項每場出陣最多觸發一次。一次表現同時解鎖數項時，合併擲一次獨立 10% 武器掉寶；每位玩家的獎勵間隔 20 秒。這不是把每個敵人的基礎掉寶率永久加 10%。

## 平衡與驗證

武器參數包含傷害、攻速、範圍、擊退、耐久、移動修正及元素／特殊效果。攻速參與命中和收招時序，動畫也使用相同的時序。五階名器已提高傷害，以補足較慢的攻速，避免原本低於部分四階武器的有效輸出。較短而快速的中階武器仍有自己的用途，階位不保證每個參數都較高。

本多普通槍擊的命中範圍與實際繪圖共用武器握點、長度及角度，17 把相容槍的前三段輕手、兩段重手均檢查接觸格的槍尖。白板首擊比較：信長 14 傷害、19 tick 收招；本多 23 傷害、24 tick 收招，白板槍首刺約 264 世界單位。阿市弓射 24 傷害、36 tick 收招、760 世界單位射程；其飛針／踢腿與弓箭分開計算。

自動化平衡檢查以真正的按鍵開始招式，量測傷害與收招，涵蓋 102 組人物／武器配對及各自的六種護符。輸出 `artifacts/native-v28/balance.json` 與 `weapon-balance.csv`。選角、物品、成就、玩家與本多站姿截圖位於同目錄。

```powershell
$env:TEST_ARTIFACT_DIR = "$PWD/artifacts/native-v28"
node scripts/test-v19.mjs --only=inventory_v28,menu_inventory_v28,balance_v28,wire,knockdown_v18,menu_pad_v27,exit_save_v27 --render-v28
```

自動化結果與原生截圖不代表實體搖桿手感、真人難度、語音聽感或跨機連線已驗收。三位較早人物仍沿用既有美術；本次沒有重畫人物或新增武器原圖。
