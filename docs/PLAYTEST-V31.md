# v0.31 玩家登入、出戰行囊與定點守糧

本機版本：2026-10-13。第二關守糧、旗號、王名與雙人復活規則後續已更新，現行版本見 [v32 修正](PLAYTEST-V32.md)。

## 操作流程

開始畫面按 Enter／Start → 玩家登入（可選單人／雙人、新增玩家）→ 選角色 → 角色狀態／出戰準備 → 出陣。角色狀態顯示實際能力與目前裝備，雙人可切換查看 1P／2P；雙人仍需不同存檔與兩支搖桿。

「倉庫／準備行囊」提供全部、刀、槍、弓、護符頁簽，保留原有物品圖片、能力、簡介、售價與出售確認。倉庫每武將 120 件。按「放入行囊」或「移回倉庫」準備本次帶出的逐件物品；行囊最多 **兩把武器、兩個護符，包含裝備中的物品**。不同耐久的同款武器仍是獨立物件。

滑鼠點頁簽，搖桿 L1／R1 切換種類；Tab 可切換選單焦點。

白板是每名角色的常備武器，無限耐久、不佔行囊。沒有帶收藏武器、卸下收藏武器、武器損壞或丟棄後，都使用白板；剩餘備用武器由玩家自行裝備。白板保留原有完整基礎攻擊，不再套用徒手減傷。

## 戰場拾取與丟棄

- 拾取武器／護符只收入行囊，不自動裝備；滿的是該類別的兩格時，該類物品留在地上。
- 食物直接回復生命；附近有收不下的武器，也不會擋住拾取食物或另一類有空位的物品。
- 暫停只可開啟各玩家的戰場行囊，換裝、使用白板、卸下護符或丟棄；出戰中沒有倉庫、出售或圖鑑換裝入口。
- 丟棄先顯示具體物品與「永久消失，不能再撿回」確認。確認後直接刪除，不產生地上物品。取消或存檔失敗都保留原物品。
- 地上護符顯示名稱；白板在 HUD 顯示 ∞。

## 掉寶率

非食物的原基準全部乘 0.1；使用千分位抽籤保留小數機率。

| 來源 | 武器 | 護符 |
| --- | ---: | ---: |
| 一般敵兵 | 0.5% | 0.2% |
| 小王 | 1.5% | 0.8% |
| 大王 | 3% | 1.8% |

特殊表現另有 1% 武器掉落機會，同場每項一次、獎勵間隔 20 秒。原有藏寶道具的非食物掉落改為 10%；食物機率、每場景最多兩份食物的既有規則保持原設定。

## 第二關

一般織田敵兵改用第一關同級的 v19 清晰素材，動畫、投射物握點與陰影共同採用該來源，實際陣營保持織田。三名頭目使用新繪十字槍、短槍、長槍素材；最初生成的短桿突刺／橫掃候選未啟用，改用完整前後槍桿的寬幅圖。註冊以站姿與頭部尺規定比例，避免蹲姿被放大；近戰距離取註冊圖中槍尖相對腳點的世界距離，並乘上頭目的實際顯示比例。

三種頭目各新增六張專用反應：受傷後仰、受傷彎身、跪倒、跌落、伏地、起身。傷害、暈眩、抓住、拉扯、擊飛、倒地、死亡與恢復均接入新圖；恢復最後回到真正站姿，不旋轉站姿或平移身體來假裝倒地。死亡依所選喊聲時長依序崩倒，最後保持平躺；空中落地直接接伏地，冰凍保留受凍當下的姿勢。身體與陰影共用同張姿勢與地面接觸點，低姿態維持固定解剖尺規。

原 PNG、SHA 與註冊保存在 `game/assets/v31/enemies/`；新增的 `*-reactions.png` 使用內建 ImageGen 生成，完整提示詞與參考來源保存在 `reaction-provenance.json`。重建腳本仍是 `scripts/register-stage2-enemies-v31.py`（沿用 v19 的 Pillow／NumPy／SciPy 元件讀取器）。步態與攻擊仍使用原先已核准的五種關鍵姿勢。

第一、第三場景改為定點守糧，車子分別放在第一據點內 x=620／650。開場兩名我軍士兵看守，敵人接近後逃離，玩家接手保護。近戰、箭矢、鐵砲與火區可傷害糧車，仍有共用 90 tick 受擊間隔。清完該場景第一據點且糧車存活，兩段各獎勵每名玩家 300／450 金；失敗仍可繼續通關。第二據點不要求把車搬走或返回護送。

## 存檔與驗證

沿用每位玩家獨立的 v2 JSON：原 `inventory` 保存永久倉庫，新增 `bag_uids` 保存準備帶出的物件編號。舊存檔保持物品、耐久、金錢與進度，首次讀取只把原本已裝備的收藏武器／護符放入行囊。戰鬥保存只更新帶出的物品，倉庫中未帶出的物品不受破壞或丟棄影響。有效備份、未知版本保護及存檔失敗取消離開仍適用。

驗證涵蓋實際登入與選角流程、分類倉庫、兩類容量、滿格拾取與食物、取消／確認丟棄、失敗保存保留物品、v2 遷移與重讀、兩名玩家分離、定點守車、兵種、槍尖與命中範圍，以及相關平衡、陰影、手把事件、物品選單、網路快照和退出存檔回歸。原生畫面與日誌在 `artifacts/departure-v31/`。
