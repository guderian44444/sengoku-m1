# 吞食戰國 M1 戰鬥原型試玩說明

版本：`sengoku-m1-0.7.0`。Windows 64 位元原生戰鬥原型，新增方向上挑、震地衝擊、由小到大的蓄力特效，修訂步態與人物比例，阿市滿弓後保持姿勢。保留木樁練習、三波關卡、無敵必殺、抓人肉盾與 IP 直連。

## 先用鍵盤試手感

解壓縮整份試玩包，雙擊 **`啟動鍵盤練習場.cmd`**，直接進入信長與 DUMMY 木樁的練習場。無須另裝 Godot 或 Node.js。

- `W A S D` 移動，`J` 連按三段輕擊，`K` 短按兩段重擊；長按約 0.58 秒再放開為獨立蓄力。
- `W＋J` 上挑／上揚短針，可以把輕型小兵挑離地面；信長 `S＋K` 直接震地，擴散震波擊倒周圍地面敵人。阿市 `S＋K` 仍使用長弓。
- `空白` 跳躍、`L` 近身按住抓人、放開飛摔，`U` 施展期間無敵的必殺。練習場怒氣自動補滿。
- `1` 木樁試招，`2` 肉盾演練：抓住近處木樁，面向弓兵擋箭，再把木樁扔向小兵。
- `R` 重置木樁與命中統計，`Tab` 切換信長／阿市，`Esc` 開啟選單。
- 木樁不反擊且不會死亡；受擊、硬直、擊飛與落地使用正式戰鬥判定，停止命中約兩秒後回位補血。
- HUD 顯示當前招式、命中次數、最近傷害、累積傷害與連續命中。

信長先直劈、再上揮、最後寬幅橫掃；上揮可以挑飛輕敵，第三刀仍能接中。阿市依序左手、右手、轉身投針，第三發擊飛。K 使用各自重武器，長按釋放為獨立蓄力技。連段須新的按鍵；按住 J 不會自動打完整套。失去視窗焦點會暫停練習並安全放下被抓敵人，回來後先放開按鍵，再繼續。

蓄力時，刀焰／手部光芒與腳下光圈從小到大，約 0.58 秒達到完整蓄力，HUD 顯示「蓄力完成・放開出招」。阿市只拉弓一次，滿弓後手臂固定，持續按住不會前後反覆拉動。方向招需站在地面，起手不會順帶向上／向下滑動；上挑只讓輕型敵人浮空，震波逐圈向外傳播，每個地面敵人只命中一次。

阿市短針射程約 260，普通弓約 760，蓄力箭約 1450（畫面寬 1280）。信長必殺以大範圍火刃擊飛；阿市必殺射出貫穿長箭，附帶暈眩。兩人必殺整段動作無敵，保護不會延長到收招結束後。

按住 L 可抓住敵人、緩慢移動及轉向；抓取容許前方 105、上下 55 的距離，優先抓最近的合格敵人。敵人貼在身前，最多抓三秒。前方的箭與輕攻會先傷到肉盾，伴隨受痛與合成哀號；背後、側面或重攻仍有威脅。三秒內主動放開 L 才飛摔，被扔的敵人可以撞倒其他小兵。抓滿三秒自動放下，需重新按 L 才能再抓；肉盾死亡或玩家被打斷也會解除抓取。

## 先看人物與環境效果

雙擊 **`啟動素材循環展示.cmd`**，直接進入雙角色展示。信長在左、阿市在右，十種動作每 2.4 秒切換，一輪 24 秒後重複。晴天、夕照、雨夜每三招切換一次；下方也可指定天氣。

- 空白鍵／搖桿 A：暫停或繼續整個展示，包含場景動畫。
- 左右方向鍵／LB、RB：上、下一招，停在該招主要姿勢。
- `[`、`]`／「上一幀」「下一幀」：暫停並移到相鄰的人物畫格。
- `S`／「速度」：切換 1×、0.5×，便於檢查動作銜接。
- F／畫面「轉向」按鈕：切換左右朝向。
- Esc／Start／「回到選單」：返回 M1 選單，再進入單人實戰或連線。

展示包括待機呼吸、輕擊、重擊、蓄力、跳攻、近身投摔、受擊、怒氣必殺、勝利與行走。招式依角色使用各自的連續畫格；受擊播放三格，倒地另用獨立姿勢。信長的刀從高位劈落、火焰由小到大再消退；阿市手臂完成出手後，飛針獨立移動。待機以四張衣袖／披風／呼吸畫格往返播放，站立位置固定；起跳與行走才移動角色位置。展示招式以實戰的 0.8× 動作速度演出，保留出手前後待機方便觀察。

一般實戰也使用新人物連續畫格。阿市的五張素材板完整改為弓道裝；抓投素材只含玩家，場上的敵人獨立呈現。實機影片中的飛針、箭與撞擊使用核心戰鬥判定；素材循環展示用來看姿勢，不代表完整交戰。角色左／右翻轉可看，上下方向尚無獨立背面圖。

## 開始試玩

1. 將整份試玩包解壓縮到本機資料夾，保留 `game`、`tools` 和啟動檔的相對位置。
2. 雙擊根目錄的 **`啟動戰鬥原型.cmd`**。
3. 選擇「信長｜近戰刀」或「阿市｜短針・長弓（演義）」，再選故事、標準或挑戰難度。
4. 按「單人開始／重新開始」。清除三波敵人及最後的大將即過關；全隊倒下則失敗。

不需要另外安裝 Godot 或 Node.js。此包附帶官方 **Godot 4.7.2 可攜編輯器執行檔**，啟動檔會用它直接執行 `game/project.godot`；目前尚未做成最佳化的正式遊戲匯出版本。

按 `Esc` 開啟選單。「單人開始／重新開始」會重置這一局；「繼續遊戲／練習」可返回暫停中的單人戰鬥。離開程式或重新開始後，進度與裝備都不會保留。

## 操作對照

搖桿按鍵採 Xbox 風格標示。其他品牌手把的實體圖示可能不同，實際映射仍需用該手把確認。

| 動作 | 鍵盤 | 搖桿 |
| --- | --- | --- |
| 上下左右移動 | `W` `A` `S` `D` | 左類比搖桿或方向鍵 |
| 輕攻擊 | `J` | `X` |
| 重攻擊 | `K`，按住再放開可蓄力 | `B`，按住再放開可蓄力 |
| 方向上挑／上揚短針 | `W＋J` | 上＋`X` |
| 信長震地衝擊 | `S＋K` | 下＋`B` |
| 跳躍 | 空白鍵 | `A` |
| 抓投／肉盾 | 靠近敵人按住 `L`，放開投出 | 靠近敵人按住 `Y`，放開投出 |
| 怒氣必殺 | 怒氣滿時按 `U` | 怒氣滿時按 `RB` |
| 拾取 | 靠近物品按 `E` | 靠近物品按 `LB` |
| 開啟／關閉選單 | `Esc` | `Start`／選單鍵 |

信長連按 `J`／搖桿 `X` 可接「下砍 → 上揮 → 大範圍橫掃」，阿市為「左手 → 右手 → 轉身末發」。三段各自使用不同連續畫格與判定。直劈集中前方，上揮挑飛輕敵，橫掃較寬；阿市前兩針原地硬直，第三針擊飛。出招期間只預存一次新的按鍵；超時或受到攻擊就中斷連段。K 短按為兩段重擊／弓箭，長按釋放為獨立蓄力技。

待機收斂頭部、肩與軀幹的晃動，保留衣物與配件擺動；地面招式依支撐腳定位。阿市改用柔和、精準的拂袖與出針動作，出招表情含蓄；受擊仍有痛苦反應。腳底保留接地陰影，跳躍時影子留在地面並隨高度縮小、變淡。路人拉近放大，四格散步與四格慌亂逃跑包含歪帽、掉鞋與散落包裹，步態按走過的距離計算。背景使用原圖與平滑縮放。

前景草叢、旗幟、火盆等裝飾只比背景稍快移動，避免橫移時快速掠過；人物與可互動物件保留地面座標。敵人的橘紅色地面框表示即將攻擊的範圍，可以上下走位避開。

飯糰恢復體力，武器增加傷害，護甲減少傷害。武器與護甲目前各只有一級；滿血時不會拾取飯糰。合成暫代音效可透過 Windows 系統音量調整。

## 兩台電腦在區域網路合作

目前支援 **一台主機加一台客端，共兩位玩家**。兩台電腦先連到同一個可互通的家用或辦公區域網路，並使用同一份 M1 試玩包。

### 主機電腦

1. 啟動遊戲，選擇自己的角色與全隊難度。
2. 保持連接埠為 **UDP `27860`**，按「建立雙人主機」。
3. 把選單列出的「本機 IPv4」告訴隊友，例如 `192.168.1.10`。如果有多個位址，使用目前連接同一個路由器的網卡位址。

### 隊友電腦

1. 啟動遊戲並選擇自己的角色。連線局的難度由主機決定。
2. 將 IP 欄位的預設值 `127.0.0.1` 改成主機的區網 IPv4。`127.0.0.1` 只代表自己這台電腦，不能用來加入另一台電腦。
3. 填入與主機相同的 UDP 埠，預設 `27860`，按「以 IP 加入」。
4. 連線及版本檢查通過後立即開始。兩名玩家各自在自己的電腦操作。

連線採 ENet／UDP 直連，由主機計算戰鬥狀態。**連線時開啟選單不會暫停全隊**，只會停止自己的操作輸入。選「結束連線／返回」會結束本次連線；隊友斷線時此局中止，需要重新開局。

若無法加入，先確認主機已建立、IP 和埠一致，以及兩台電腦使用相同版本。若 Windows 顯示防火牆詢問，依你信任的區域網路與電腦管理規則處理；此包不會自動修改防火牆或路由器。公司、訪客 Wi-Fi 或隔離網段可能禁止裝置互連。

此階段以區網雙機為目標，沒有房間列表、中繼伺服器、自動 NAT 穿透或斷線續接。尚未驗證跨網際網路連線，不保證 CGNAT 或不同路由器之間能直接連通。

## 已有內容與尚未完成的部分

目前可試：

- 信長、阿市兩位操作不同的角色；三種難度。
- 三波敵人、最後一波大將、勝敗判定與重新開始。
- 輕擊、重擊、蓄力、方向上挑、震地衝擊、跳躍、抓投／肉盾、無敵必殺、短針／長弓、武器／護甲／食物拾取。
- 左右卷動的戰場、v0.7 步態與比例修訂、既有人物逐格動畫與城下道素材、旗幟／火光／路人／天氣、敵人攻擊前兆與合成音效。
- 單人遊玩、雙人 IP 直連，以及鍵盤／標準搖桿按鍵映射。

玩家角色使用修訂畫格與各段獨立輕擊，v0.7 針對行走、信長比例與阿市滿弓保持調整。敵人目前仍是程式繪製角色；素材網頁的新敵兵造型供篩選，尚未接入這份戰鬥原型。音效及肉盾哀號仍是合成暫代音。這是動畫試作，仍需持續修整輪廓一致性、收招銜接及增加上下方向等動作。場景為概念圖搭配獨立活動物件，尚未代表正式關卡素材。

尚未實作存檔、雙人合技、角色專武、完整故事線、完整長篇關卡或原作所有系統；也沒有同一台電腦的雙人分離輸入、按鍵重綁、主機遷移及高延遲連線補償。此次原型不代表原企劃已全部完成。

## 驗證方式與待驗項目

開發檢查涵蓋戰鬥核心、連線資料格式，以及同一台電腦內兩個 ENet 程序的輸入、狀態同步和結局傳送。**本機雙程序測試不能代替兩台實際電腦的區網測試，也不能證明實體手把的映射與手感合格。**

若要自行重跑開發檢查，需另備 Node.js，在本資料夾執行：

```powershell
node scripts/test-native.mjs --capture
```

此命令會執行核心檢查及本機連線測試，最後啟動一次原生繪製並儲存截圖。測試紀錄、JSON 報告與 `m1-prototype.png` 位於 `artifacts`。截圖成功代表已產生畫面，仍需人工檢查畫面；自動模式不播放遊戲音效。

素材驗證：`node scripts/test-art-native.mjs --frames --movie` 檢查展示隔離、逐幀前後移動、半速、命中時機、素材映射及 v0.7 蓄力／步態，拍下十動作／兩角色／兩朝向截圖及 47 個展示畫格位置，並錄下 24 秒循環與 36 秒 v0.7 操作影片，使用 FFmpeg 轉成 MP4。輸出位於 `artifacts/art-native-v07`，仍需檢查實際畫面。加上 `--legacy-movies` 才額外重錄舊版 48 秒鍵盤回歸與兩刀／三刀對照。

v0.7 獨立錄影使用 `game/tests/capture_v07.gd`，由 Main 的實際鍵盤事件路徑操作，固定 36 秒：信長左右步行、漸強蓄力、上挑小兵、震波多敵，接著阿市左右步行、固定滿弓與上揚飛針。錄影與抽幀位於 `artifacts/art-native-v07`；影像成功產生仍需人工檢查動作。修訂素材位於 `game/assets/v07`：信長全套與阿市 motion；阿市其他招式仍使用 `v06` 弓道裝。既有人物圖保留於 `v04`、`v05`、`v06`，環境位於 `game/assets/v03`；圖檔以 runtime PNG 載入，無須事先在編輯器匯入。

待實際驗收：兩台電腦合作通關、實體搖桿映射與熱插拔、操控手感、真實輸出裝置的音量與音色，以及不同螢幕／顯示卡上的呈現。
