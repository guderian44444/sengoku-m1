# 第三關素材／機制狀態清單

狀態分為「可沿用／需核對／占位／待製作」。表內正式素材均未因文件建立而視為完成；已核准玩家人物不重做。兩根柱與所有戰鬥數值僅是可調原型預設。

| 優先 | 項目 | 目前狀態 | 原型／正式需求 |
|---|---|---|---|
| P0 | 玩家角色、輸入、受傷、投摔 | 可沿用 | 使用基底既有玩家 runtime／素材；不重新生成已核准人物，不整包複製未提交的新玩家素材。 |
| P0 | 盾／槍／遠程雜兵 | 可沿用＋需核對 | 既有今川兵作行為原型，M2 用「盾槍／槍／弓」字標辨識；既有盾兵部分幀缺盾錨點，正式盾牌輪廓、遠程持弓及陣形造型仍需核對。 |
| P0 | 高處警鐘、模組化支柱 | 占位 → 待製作 | 可讀高鐘與地面攻擊支柱；支柱完好／受損／重損／斷裂。鐘持續鳴響、傾斜、落下與停止狀態。 |
| P0 | 木障礙、多排封鎖 | 三層占位已接 → 待正式製作 | M2 整條行走帶碰撞、逐層破壞及破裂殘骸已接；正式完整／受損／崩裂素材仍待製作，不做繞路。 |
| P0 | 三大段營地與帳內戰場 | 三段沿用占位／帳內待製作 | M2 前營、木障、帳前沿用 camp／gate；帳內尚未接入，正式底圖與前後景分層待製作。 |
| P0 | 增援入口 | 占位 → 待製作 | 明確營門／帳簾／遠處通道標識，進場到後排路徑可讀；不能在玩家腳下瞬間生成。 |
| P0 | 小王 A／B | 占位 → 待製作 | 使用不同色標／輪廓區分；正式外觀與姓名待設計，需後撤、反制與完整受擊／死亡。 |

| P0 | 箭、刀氣 | 可沿用核心＋需核對 | 分開出手、飛行、命中；核對預警、尺寸、起點、速度與命中體，不以換顏色當完整新招。 |
| P0 | 格擋火花、碎木、塵土 | 可沿用占位 → 待製作 | 事件驅動；正式清楚但不遮擋支柱進度、陣形缺口及玩家輪廓。 |

| P0 | 支柱進度、雙小王血條 | 支柱占位已接／雙血條待開發 | M1 頂部顯示已破壞柱數／總柱數，每柱有 HP 條；兩小王各自姓名代號／HP 尚未接入。 |
| P1 | 專屬配樂與語音 | 待製作 | 原型可沿用基底音樂；正式義元／小王台詞、配音與章節配樂另驗收。 |
| P1 | 裝飾旗幟、完整轉身／武器切換 | 待製作 | 後續加強身份、空間與武器連續性；不以原型占位宣稱正式完成。 |

| 機制 | 可沿用 | 需要新增／核對 |
|---|---|---|
| 目標物 | hp、broken、prop_hit／prop_break、碰撞 | 支柱 group、全毀停鐘、階段專用目標完成條件 |
| 增援 | 畫面外進場、角色建立 | 有界逐人排單、容量預約、取消、指定入口；禁止舊 30 秒整批援軍與新排單同時運作 |
| 陣形 | 敵人移動與碰撞、盾槍／弓兵 | M2 已接錯落站位、缺口時窗、唯一補位預約、真實行走與後排准入；正式兵種識別與難度仍待核對 |
| Boss | HP、格擋／反擊、招式時序 | 雙領袖設定、成對入場、雙血條、客製目標、有限後退及義元兩招遠程 |
| 關卡／同步 | 章節發現、GO、主機權威快照 | 第三關遭遇資料與 Wire 校驗、持續狀態／事件、三大段與兩階段帳內戰 |

正式完成判準：素材來源／版本可追溯、真透明分層、逐格時長與握點明確、原生畫面驗證；占位可運行不代表正式美術完成。原型數值、有限掉落、危險招協調與後撤上限均可調，不標成使用者已指定。

M1 原生畫面已核對完整柱、重損、單柱斷裂及全斷落鐘；來源為既有營地底圖加程式幾何占位，沒有重新生成玩家人物。見 [M1 驗證紀錄](STAGE03-VALIDATION-M1.md)。
