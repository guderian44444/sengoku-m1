# 第三關機制原型：簡易試玩

目前可從警鐘一路玩到義元死亡結算。第三關保持 `prototype: true`，正常章節選單仍不顯示；人物、場景、弓與效果含占位。只在 `feature/stage03-imagawa-camp` 的獨立 worktree 啟動，不需切換主目錄分支。

## 啟動

在 PowerShell 執行：

```powershell
Set-Location 'D:\AI\吞食戰國\artifacts\stage03-imagawa-camp'
.\scripts\play-stage03-alarm.ps1 -GodotBin 'D:\AI\吞食戰國\tools\godot-4.7.2\Godot_v4.7.2-stable_win64_console.exe'
```

沿用的腳本名稱仍有 alarm，目前會啟動完整四場景原型。單人使用信長；加 `-Coop` 可用信長／阿市同機雙人，需兩支搖桿。加 `-StartScene 3` 可直接進帳內雙小王，再打義元；`0／1／2／3` 分別是警鐘／木障／陣形／帳內。

啟動器將資料隔離在 worktree 的 `artifacts/stage03-playerdata/`，專用入口停用角色進度寫回。視窗失焦會沿用既有暫停，回來後放開按鍵並按繼續。日誌在該隔離目錄的 `play.log`。

## 操作與通關順序

- 鍵盤：WASD 移動、J 輕擊、K 重擊／長按蓄力、Space 跳、L 按住抓人／放開摔、I 防禦、U 必殺、E 拾取、Esc 暫停。同方向雙點後按住可衝刺。
- Xbox：左類比／十字鍵移動，X 輕擊、B 重擊、A 跳、Y 抓人、LT 防禦、RB 必殺、LB 拾取、Start 暫停；PlayStation 對應 □／○／×／△、L2／R1／L1／Options。雙人各一支搖桿，鍵盤只控制 1P。
- 警鐘：攻擊地面兩根支柱，全部打斷停鐘，清除現有雜兵後沿 GO 向右。高鐘本身不是攻擊目標。
- 木障：三排都必須打破，再清場沿 GO；上下緣與跳躍不能繞過。
- 陣形：利用補位前的缺口突破，全員越過前線並走到右側帳門；不用清光陣形士兵。
- 帳內：A／B 各有一條血，任一王還活著就持續補雜兵。兩王皆倒後短暫安全出場，再切義元單血條。
- 義元：避開箭與較寬刀氣，利用正面格擋後的收招、側後方或重擊。義元死亡即顯示「第三關機制原型突破！」，剩餘雜兵不阻擋結算。
