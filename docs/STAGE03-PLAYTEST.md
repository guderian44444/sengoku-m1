# 第三關「今川本陣」試玩

主目錄已整合第三關；第二關通關後可由正式選關進入，沿用玩家分檔與保存。要直接體驗，雙擊根目錄的「啟動第三關試玩.cmd」。這個捷徑使用隔離資料，不寫回正式角色進度。

進階啟動：

~~~powershell
.\scripts\play-stage03-alarm.ps1
.\scripts\play-stage03-alarm.ps1 -Coop
.\scripts\play-stage03-alarm.ps1 -StartScene 3
~~~

StartScene 0／1／2／3 分別是警鐘／木障／陣形／帳內。雙人需兩支手把，鍵盤控制 1P。專用入口固定信長／阿市，資料及日誌位於 artifacts/stage03-playerdata/。正常出陣選角請使用主選單。

操作與目前版本一致：WASD 移動，J 輕手、K 重手／蓄力、L 抓技、空白跳、E 拾取、Esc 暫停；手把為 □／X 輕手、○／B 重手、R2／RT 抓技、×／A 跳、L1／LB 拾取。抓住後輕手連打或反向摔。完整操作見 [試玩說明](../README-試玩.md)。

1. 雨營警鐘：擊破兩根地面支柱，落鐘停援，再清除餘軍向右進軍。高鐘本身不是攻擊目標。
2. 重重木障：打破三層封鎖；跳躍與上下緣不能繞過。
3. 本陣防線：打出缺口，趁敵軍補位前突破。全員抵達右側帳門，不必清光士兵。
4. 今川大帳：擊敗井伊直盛與蒲原氏德，接著迎戰今川義元。留意放箭、刀氣、正面格擋與收招；義元敗北即進入大捷結算。

前三關共用完整音樂流程：接敵換曲、敵將覆蓋、雙將與義元專曲，勝利短句自然結束後接循環。暫停會凍結播放，退出會清理鐘聲及配樂。
