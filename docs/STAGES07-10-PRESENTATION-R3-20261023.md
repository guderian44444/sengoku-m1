## 四關一起修正

| 項目 | 現行行為 |
|---|---|
| 區域背景 | 四關共 20 個區域各有獨立背景，新增 16 張同風格全景。美濃為竹徑、棧道、山口、峭壁及守隘；岐阜為外門、折角坡道、守門內郭、二之丸及室內本丸；上洛為渡口、町屋、封鎖線、勝龍寺外街及本陣；金崎為撤軍口、雨中山徑、追擊陣、渡橋及退路。近景建物、遠山及地面比例隨區域改變。 |
| 火槍射程 | 長井及四關普通鐵砲兵均射穿整個可行走作戰區，後退超過原瞄準位置仍可能中彈；保留前方掩體阻擋與換線躲避。使用有限的全區射線，不把無窮數值送入連線快照。 |
| 火槍表現 | 有瞄準火點、槍口焰、煙與胸口高度的子彈軌跡；交叉火線、掩盾支援與普通兵共用相同繪製。 |
| 長井炸彈 | 投擲起手 18 ticks，飛行 26 ticks，合計約 0.73 秒到爆破；可見陶製火藥彈、引信、拋物線、爆焰及煙塵。落點在投出時鎖定，躲避仍有效。 |
| 箭雨 | 所有環境及頭目箭雨改為每批 8 個疏落點，橫向約 840、縱向約 224 的散布區，逐箭 26–50 ticks 落下。參考阿市的箭身繪法與錯時落下方式，位置由固定種子散布；每支箭的實際落點才有傷害，不再按三條整齊橫列整片判定。 |
| 危險區及近戰 | 移除新四關的矩形框及倒數線；地面陰影、淡橢圓輪廓、瞄準線提示，配合實際飛行物、刀光、碎石或地裂塵土。空中物件隨落點深度排序。 |
| 龍興反應 | 拔刀雙斬改為第 20／32 tick 命中、整招 62 ticks；反擊起手 32 ticks，箭雨起手及招後時間亦縮短。保留連擊護身反制及繞背／蓄力開口。 |
| 登場語音 | 八段既有配音沿正式主程式播放，新增依登場狀態補播，避免漏接單次事件；台詞播放時音樂暫降至原設定的 20%，結束後恢復，不改寫玩家音量偏好。測試未重現每次必定無聲，故不將單一未證實原因當成根因。 |

圖片由內建 imagegen 產生，存於 `game/assets/stages07-10/backgrounds/sXX-N.png` 及 `props/powder-bomb.png`。提示詞、參考圖及來源完整保存在 `generation-regions-r3.json`、`generation-bomb-r3.json`，納入 `runtime-files.json` 的 SHA 登錄。刀光、槍火與爆焰沿用專案現有 VFX。
