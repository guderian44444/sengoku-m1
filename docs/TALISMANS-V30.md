# v0.30 三十種護符

名稱、組合與數值是遊戲創作；史料只支持信仰題材，不證明現實能力或戰國時代有同名商品。

一次只裝備一件。定值護盾用盡消失；百分比減傷依剩餘耐久衰減，剩 20% 耐久損壞。其他加成在護符完好期間固定有效。所有護符沿用相同存檔與出售規則。

新增款以初始減傷 6–18%、攻速最多 +6%、移動最多 +10%、條件傷害最多 +12% 為上限。高階款有二至三項小加成，不能疊戴。原有六款保留既有數值與 ID。

## 功能結算

重手含 heavy／dash_heavy／upper_heavy／ground_slam；蓄力含 charged／charged_upper／charged_slam；空中含 air_light／air_heavy。條件傷害只增強該次直接命中，不增強後續燃燒、中毒或環境傷害。必殺加成只對 special 的直接命中。成功防禦怒氣每次真的擋住一擊才給；擊殺怒氣每個敵人只給一次。食物加成按實際可回復生命封頂。抗性縮短新施加的異常時間，不給免疫。

掉落：原關卡六款固定藏寶保留；雜兵／小王／大王另外以 2%／8%／18% 擲護符掉落，第一關最高三階、第二關最高四階。護符與武器掉落各自擲骰；行囊滿時保留地上物品。
