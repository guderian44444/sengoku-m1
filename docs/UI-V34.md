# UI 整理與操作驗證（2026-10-15）

字型與按鈕已依核准預覽更新為MasaFont Regular／02紅錦卷軸；本文件保留v34操作基底，現版樣式與原生圖見[最新交接](UI-MASAFONT-SCROLL02.md)。

目前 runtime 版本仍為 0.33.0；本文件的 V34 是介面整修測試批次，未代表已發布新版本。

- 主選單、玩家登入、點將、出陣準備、倉庫、圖鑑、成就、設定、暫停、確認、演武連線及操作表共用紙色／墨字／朱紅焦點主題。
- `game/render/game_typography.gd` 統一載入莫大毛筆 Bakudai Regular，附 OFL 授權、固定上游版本與 SHA256；罕字由兩個隨附字庫補字，不依賴使用者電腦字型。
- `game/assets/current/ui/title-logo-v34.png` 是內建 ImageGen 生成的透明草書日文標題與英文副標；完整生成提示留在同目錄 `.txt`，原始輸出未經影像後製。
- `game/ui/menu_input.gd` 管理各頁焦點、清單邊界、捲動與多裝置輸入；原生下拉選單保留 Godot 行為。
- `game/ui/controller_keyboard.gd` 支援姓名常用字盤、英數符號、刪字、取消／確認、IP 與連線埠。常用姓名字盤不等於完整中文輸入法；需要其他漢字時使用實體鍵盤與系統 IME。
- 遊戲內統一使用武者名簿、出陣支度、藏兵閣、兵器圖錄、戰功簿與合戰秘卷；保存錯誤、永久丟棄及連線條件仍明確呈現。圖錄去除製作筆記與資料欄位名稱，保留史料分歧、演義改編與來源。
- `game/ui/objective_scroll.gd` 以紙卷、木軸、金帽與朱印顯示令旨，依據關卡實際守軍、敵將、排定波次、路障與進軍狀態換令；暫停、對話及勝敗時收起。
- 玩家、敵將與小兵血條加上墨底、暗金細框及端飾。小兵條身為 54 × 7 像素，距當前姿勢可見輪廓頂緣 20 像素；蓄招時另避開攻擊提示。7 像素是以 1280 × 720 畫面抓取約 2 mm 的視覺厚度，實際毫米數依螢幕及縮放而異。血量、填色與死亡隱藏規則保留。
- 角色與倉庫資料沿用原流程，退出仍由原有保存成功條件決定；測試使用隔離 APPDATA，不操作正式存檔。

## 追加：粗筆與深色按鈕（v35 檢查批次）

依使用者回饋，共用毛筆字及兩個補字庫透過 FontVariation 加重筆畫（embolden 1.0）；選單、按鈕、輸入、彈窗、卷軸及戰鬥畫字均共用此字體。原字型檔與文字大小保留。

按鈕改用深褐木色，懸停為較亮褐色，按下為深朱紅；字色改暖米白。紙面與輸入底色加深為舊紙色，停用按鈕以灰褐區分。明暗背景各使用相應焦點色，保持可讀對比。新原生截圖與驗證位於 `artifacts/ui-bold-v35/`。

依後續「邊框太亮」回饋，搖桿焦點與懸停邊線由亮金改沉古銅色；畫面內圈改暗金半透明線，標題及主選單的米黃色厚底框改深褐色。文字維持原亮度。原生截圖與驗證位於 `artifacts/ui-border-v35/`。

按鈕追加深色和紙札造型：非對稱切角、細纖維、兩端青海波紋及內封邊；選中時保留暗古銅粗線，另以小朱印標示焦點。四種共用按鈕（Button、OptionButton、CheckButton、CheckBox）及各狀態同步套用，姓名鍵盤也共用；原點選範圍、文字留白與導航不變。以 StyleBox 自繪，不新增貼圖或套件。主題測試涵蓋小按鍵至寬按鈕的閉合輪廓及邊界，長內容版面與原生頁面流程驗證通過；15 張畫面位於 `artifacts/ui-button-v35/`。本次未進行實體搖桿驗收或另建發布包。
