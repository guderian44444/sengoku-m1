# 六名武將獨立聲線

日期：2026-10-13。本輪檢查六名可選武將的登場、發力、重手、受傷、防禦、必殺、勝利、敗北與敵將討取。

## 舊版發現

六人沒有共用同一段 PCM 或誤接別人的台詞，但製作來源不一致。信長、阿市的短喊已更新；秀吉、家康、光秀、忠勝仍混用 v10 完整台詞與 v11 發力聲。v10 五名男角使用同一個 `ja-JP-KeitaNeural`，主要靠音高／速度區別。短喊與防禦路由合計 19 段不在 0.30–0.50 秒範圍，四人的勝利池只有一段。

每人另有登場、完整必殺、敗北與敵將討取各一段，共 16 段獨立錄音；防禦使用該人物自己的三段重手池。六人共 96 段，沒有跨人物借音。輕手一／二、普通重手一及未蓄力的方向、空中、衝刺重手沿用只播武器音效的規則。

每人先由 VoiceDesign 生成一個原創合成的登場參考聲線，再由 Base 使用相同參考錄音產出其餘台詞，依照 [Qwen 官方 Voice Design then Clone 流程](https://github.com/QwenLM/Qwen3-TTS#voice-design-then-clone)。參考聲線、原始音、seed、模型 revision、處理流程與 SHA 保存於 manifest／artifacts。未使用真人演員錄音或仿冒真人聲音。

六人以原音高播放。忠勝使用低沉的參考錄音，不再靠 runtime `pitch_scale=0.88` 調整。參考音高量測只用於排除明顯偏離角色聲線的生成結果，不等於表演或聽感驗收。

## 播放與資料

入口是 `game/audio/v30/manifest.json`。沒有完整 manifest 時仍使用原本版本；生成腳本只在六人全部完成、各池數量與 SHA 驗證後發布。v10／v11／v14／v15／v27 原音檔保留。原有敵軍路由與敵將開場／死亡時間資料沿用。

兩名玩家仍用獨立語音通道；命中事件取挨打者的受傷池。亂數袋走遍各種 take，相鄰不重複；必殺、受傷、敗北能打斷該人物原來的短喊。

逐人及逐句試聽：`artifacts/voice-v30/preview.html`，六人合輯：`artifacts/voice-v30/six-heroes-preview.wav`。完整原始生成音與落選 take 只留在本機 artifacts；遊戲使用正式 WAV，不需要執行 TTS 模型。

## 驗證

生成階段檢查短喊長度、音量、削波、單段發聲、來源 SHA 與參考聲線；Godot `test_voice_v30.gd` 檢查六人的九種事件、各自 PCM、雙人互不覆蓋、受傷者路由與原敵軍時間資料。語音／音效分類音量及舊短喊時機由既有音訊測試覆蓋。

本次七組原生測試通過，共 4,106 項檢查：`voice_v30`、`audio_v11`、`audio_v14`、`audio_v15`、`audio_v20`、`victory_v15`、`victory_integration_v15`。檔案獨立檢查確認 96 段 PCM 各不相同、54 段短喊都在 0.30–0.50 秒，全部正式音量有界且未削波。原 76 段主角音檔的 PCM 完全保留。

舊勝利測試的兩項前提已按現版修正：用最後一命建立真正敗北的隊友，並經過退出確認；最後勝利格在台詞未播完時保持，兩人都播完後應進入可移動拾取狀態。修正只涉及測試場景，沒有改動勝利或退出流程。
