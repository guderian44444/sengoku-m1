# 武將語音的動作情緒修訂

日期：2026-10-13。這次針對「阿市像呻吟、本多像平淡念台詞」以及六人發力、痛苦、激昂的表演區分，重新製作角色語音。

## 原因與製作方式

v30 的 Base 複製回呼接收了 `_description`，實際生成時沒有使用情緒指令；各句因此主要跟隨登場參考錄音的表演。本多的舊設定也明寫平淡語調與不要喊叫，與攻擊、必殺及討取的要求衝突。

新版使用 [Qwen 官方 CustomVoice 1.7B 模型](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice#custom-voice-generate)，每人固定一個模型聲線，每段直接傳入聲線與該情境的表演指令。試做的 VoiceDesign、聲線混合和過高音域候選只留作本機比較，沒有接入遊戲。新版六人聲線會與 v30 不同。

角色設定與完整指令在 `game/audio/v31/profiles.json`，製作腳本是 `scripts/generate-voices-v31.py`；模型只在製作時使用，遊戲播放正式 WAV。原模型、原始錄音與落選候選留在 `artifacts/voice-v31/`，每段保留 model revision、seed、原音與正式檔 SHA。

## 接入與檢查

六人各 16 段，共 96 段：登場、必殺、敗北、討取各一段，發力、重手、受傷、勝利各三段；防禦使用該人物的重手池。短音維持 0.30–0.50 秒，僅去除頭尾靜音並微調節奏，保留完整發聲。高通從 100 Hz 改為 60 Hz，保留低男聲的低頻；播放音高仍為 1.0。

`scripts/test-voices-v31.py` 用替身模型確認發力、痛苦、勝利三種指令真正送到 `generate_custom_voice`，且使用固定的角色聲線。正式錄音另檢查完整池、長度、音量、削波、不同 PCM、來源 SHA；Godot 檢查真正播放的檔案、受傷者路由、雙人分離、短音時機與勝利／頭目時間資料。

新舊逐段比較：`artifacts/voice-v31/preview.html`。六人個別合輯是同目錄的 `*-preview.wav`。

八組原生檢查共 4,316 項通過：角色語音 1,483、音量／靜音 69、短喊時機與打擊音 474、變化音池 216、武器音效／放招 916、勝利動作 1,051、勝利流程 18、倒地與頭目死亡 89 項。結果在 `artifacts/voice-v31/native/results-v19-20261013T145753649Z.json`；另有 96 段正式來源 SHA、54 段短音長度與無削波、六個固定聲線，以及舊檔保存的獨立檢查。以上數字不代表真人表演驗收。
