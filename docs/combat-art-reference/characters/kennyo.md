# 本願寺顯如攻擊畫面要素

顯如取代光秀的角色位置，主武為棍類，包含長棍、長柄錫杖／法杖／杵。普通重手是收杖、前進一步、往上打，將前方敵人較高地擊飛。按[共通規格](../README.md)拆成人物、武器、效果。

## 身份與造型

歷史身份為本願寺第十一代宗主顯如，見[西本願寺官方歷史](https://www.hongwanji.kyoto/know/history.html)。持杖格鬥、僧兵護甲與下列造型為遊戲改編，不宣稱是顯如實際使用過的兵器或史實戰法。

造型方向：剃髮、念珠、僧衣配局部護甲，適合厚重近戰與大幅揮杖。臉、年齡呈現、體型、僧衣配色、念珠尺寸、鞋與基準武器形制待確認；先建立一張身份站立圖，再生成全套動作。不能沿用光秀的臉與白紫衣後只換法器，也不能把家康的甲胄當顯如皮膚。

## 普通重手與滿蓄的畫面差別

普通重手六節點為近身收杖、前移預備、一步落腳、由下往上接觸、較高上揮隨動、站穩。它不是原先誤寫的滿蓄兩步上打。

滿蓄仍保留高舉武器、單手握尾端、頭頂水平兩圈。換握點要有可讀交接，環／杵頭與桿保持同一件武器；手臂不能穿頭、短小金剛杵不能被假拉長成兩米長棍。若選杵，需先確認適用于本招的長柄形制。

## 分件與握點

頭、念珠、軀幹、僧衣前後／袖片、局部甲、上下臂、左右手、腿與腳分開。寬袖／僧衣需補被遮住的肘與膝，避免紙偶接縫；念珠的後段與胸前段分層。滿蓄另外量測單手尾端握點，普通揮擊量測主／輔手桿軸，兩者不能沿用同一錯誤支點。

## 本角色檢查

先確認身份圖；不是改光秀名字繼續用舊臉。前兩段輕手均揮擊，第三段一圈；普重收杖一步上打，滿蓄另是頭頂兩圈；法器外形不自動增加新魔法。棍類裝備與新角色接入另外處理，不能用重命名光秀存檔替代。詳見[武器](../weapons.md)與[效果](../effects.md)。
