# 信長攻擊畫面要素

主武為刀；普通重手固定為高舉下斬加中距離劍氣，命中擊退而非擊倒。人物、刀與鞘、效果依[共通規格](../README.md)分開製作。

## 身份與動作風格

身份參照[現有站立來源](../../../archive/legacy-before-v33/game/assets/v22/nobunaga/idle.png)與同資料夾的最新登錄。保留既有臉、鬍鬚、束髮、暗紅黑甲、金邊、紅披風與腿部比例；參考圖中的刀柄不烘焙到新人物層。穩定低重心、較寬揮幅、雙手發力。披風跟隨身體延遲，不用披風遮掉握點或腳。

## 重手關鍵姿勢與早期試作

最初以起始、高舉、下斬到底三張定義招式。12 張是早期播放影格數，不要求每張都獨立生成；後續依要求補中間格，整套版重手為 25 張，增加預備停留與回正。刀與劍氣使用外貼獨立素材。輕手三段各自製作多張動畫，後續按鍵才依序銜接，各段可採不同張數。

1. 起始：雙手在頭側預備，雙腳分開，握點清楚。
2. 高舉：雙手抬過頭，肩、肘、腰保留發力張力。
3. 下斬到底：前腳支撐、雙腳承重、手收於前方低位，刀刃沿前方停住，不插入地面。

劍氣在下斬通過接觸方向後外貼觸發；命中設計為敵人站立擊退。收招可另接共用待機姿勢。參考[12 張分層版本](../../../prototypes/nobunaga-heavy-12-v1/README.md)、[三張光流基準](../../../prototypes/nobunaga-heavy-3key-v1/README.md)與[補一張的 16 影格版](../../../prototypes/nobunaga-heavy-4key-v1/README.md)。最新試作用同套第 06 張補下斬，原三張保留；副手按刀柄軸線定位並另貼手指前景。素材驗收優先看關鍵張外觀／尺規／配色與握持，高速補間依遊戲尺寸檢視。

## 分件與握點

頭與束髮、軀幹甲、上下臂、左右手、骨盆甲片、上下腿、腳掌、披風各能獨立處理。披風後側與身體前側分層；雙手各有手指遮擋片。兩手不要在同一招中突然互換，不能以整張人物旋轉代替腰肩發力。旋轉需有正、側、背方向；甲片、家紋、髮束位置保持身份一致。
