# 攻擊效果素材與觸發畫面

搭配[共通規格](README.md)與[武器運動](weapons.md)。FX 索引為製作清單；不是現有 runtime 已註冊的 ID。優先檢查共用效果接入（歷史runtime文件：`../SHARED-VFX-V30.md`）中的可重用素材，再補缺項。

人物、武器、效果分開：箭是武器／彈體，箭尾才是效果；刀是武器，劍氣是效果／攻擊表現；被擊飛者是另一人物，不是特效圖。效果的顏色不能自行追加火傷、冰凍、雷擊或其他未確認的狀態。

## 材質與分層

效果使用與角色相符的繪製銳度與透明邊緣。刀／槍接觸為金屬刃感，棍／杵與弓打為鈍擊；念珠、衣服不冒出與接觸無關的亮光。短刀弧不能蓋住臉、持握手、槍尖或箭尾扣弦點。

先做中性效果；人物既有元素或實際裝備的配色，在合成時選版本／著色。不能因阿市有冰色、顯如是僧人，就自動加入凍結、治療、召喚或法陣傷害。顯如目前仍用棍系物理攻擊。

每項輸出真透明 RGBA，記錄序列／循環范圍、中心或接觸錨點、前後層、方向、啟動／停止事件。沒有真正接觸時，揮擊尾痕可有，命中爆點與敵人控制反應不可憑空播放。

## 施放事件順序

| 招式 | 效果與人物／武器事件順序 |
| --- | --- |
| 輕手 | 承重踏步 → 揮擊痕 → 確認接觸命中 → 前兩段擊退或第三段擊飛 → 收招 |
| 信長普通重手 | 高舉預備 → 下斬刀弧 → 發出劍氣 → 確認接觸擊退 → 波與刀弧消退 |
| 家康普通重手 | 收刀／鞘口保持 → 拔刀刺線 → 前突接觸 → 速度痕消退；被命中者的控制效果待確認 |
| 忠勝普通重手 | 長刺線 → 多目標接觸 → 抽槍事件 → 被刺中者倒地 → 各自落地塵 |
| 刀槍棍滿蓄 | 集氣提示 → 滿蓄保持 → 放開、蓄力提示結束 → 第一圈 → 第二圈 → 收招、所有旋圈效果消退 |
| 阿市滿蓄前射 | 集氣提示 → 滿蓄保持 → 箭離弦、集氣停止 → 箭尾 → 每個實際接觸擊退；箭繼續穿透 |
| 阿市箭雨 | 滿蓄轉蹲、抬弓 → 一箭朝天離弦 → 箭出畫面 → 立刻落箭與箭尾 → 區域接觸擊倒 → 落地塵 |
| 空中重斬 | 舉武器 → 下降揮痕 → 武器接觸 → 人物馬步落地塵；敵人擊倒／落地另按事件 |
| 抓摔 | 頭槌／膝擊各兩次接觸 → 第三次鬆手 → 拋出尾痕 → 被投者碰人爆點 → 各人物落地塵 |

暫停、中斷、角色消失、切場景或取消施放時，所有跟隨／循環效果要能停止；不預設中斷後箭雨或旋圈仍完成。數值判定待確認的部分保留事件接口，不以效果動畫倒推出傷害次數。

## 效果層生成提示

```text
獨立 2D 遊戲 <效果名稱>，匹配既有繪製風格與銳度。
只畫效果，真透明 RGBA，無人物、武器、受害者或地面背景。
方向 <前向／前下／頭頂水平圈／腰部水平圈／落地>。
序列為開始、最大、消退；循環的蓄力另提供可平順接續畫面。
中心或接觸點可清楚量測；邊界有透明空間；不添加文字或未指定法術。
```

驗收時分別觀看無特效的招式、純特效、完整合成。若沒有特效就看不出刀路／拉弓／兩圈旋轉，先修人物與武器，不能以更大的光圈掩蓋動作缺口。
