# 攻擊武器素材與運動

搭配[共通規格](README.md)與各角色動作表。所有武器獨立透明輸出，人、握持手指與光軌不烘焙進武器。以下 W 索引是製作項目，不是已存在的程式事件或資產名稱。

## 武器本體

| 類別 | 需要的獨立素材 | 支點與必要視角 |
| --- | --- | --- |
| 刀 | 完整刀身、刀柄、鍔；合適刀鞘另圖 | 握點、刀尖、柄尾、鍔、鞘口。側視與必要的斜向／背向轉角；家康另需刀身抽出階段的遮擋 |
| 長槍 | 完整槍刃、槍桿、槍尾；掛繩等保持同一位置 | 主／輔握點、槍尖、槍尾。長桿不可截短、刃寬不可忽大忽小；頭頂旋轉的斜向投影另做 |
| 棍杖杵 | 長棍、長柄法杖／錫杖／杵可替換 | 握點、尾端、頭部。重量與頭形保持一致；錫杖環、杵頭不生成成新的手或刀刃 |
| 弓 | 完整弓身與弓柄；需要受力形變時提供張弓版本／可變形幾何 | 握點、上／下弓梢、弦接點；不烘焙弦或箭。保持日本長弓的已確認形制，不任意換成短弓 |
| 弦 | 線段或獨立弦圖／幾何 | 上弓梢、拉弦手指、下弓梢三點；放弦後回到兩弓梢直線 |
| 箭 | 一支完整箭：箭頭、箭桿、箭羽 | 箭尾扣弦點、尖端、飛行軸；側視與朝天／前下的必要投影 |

每件記來源、SHA256、裁切、握點、完整本體長度與物理形制。視角投影可以縮短可見長度，武器本體不因人物蹲下或裁圖高度改變實際長度。兩手握持要保留固定桿軸，換較長武器時仍從量測握點合成。

單刃刀另記刀尖軸向與切刃朝向。上揮時切刃朝上方的切入方向，刀背在後；不能只把刀尖從低轉高。反斬的轉腕、低位蓄勢、腰肩發力與刀柄握持一起交代，連段交接格先完整沿用前段的刃向，之後才在預備段翻刃。

## 地面輕手與普通重手

| 索引 | 武器運動 | 人物接口與接觸畫面 |
| --- | --- | --- |
| W刀輕 | 斜／橫揮、反向揮、大幅橫斬三段 | 刀尖沿手臂與轉腰的軌跡走；三段各跟隨一次前踏，第三段範圍最大 |
| W槍輕 | 直刺、再刺、橫掃 | 刺時槍桿沿兩手軸推出，抽回後接第二刺；橫掃轉腰，不整根亂甩出握點 |
| W棍輕 | 左揮、右揮、較大範圍甩一圈 | 前兩段均揮擊；第三段水平環繞，轉向與前後遮擋可辨識 |
| W弓輕 | 弓身左右打、大幅掃擊 | 以弓柄為握點；弓身直接接觸。弓弦維持未拉開狀態，不產生箭 |
| W下斬劍氣 | 高舉刀後向前下斬 | 刀尖／刃先通過接觸方向，再發前方中距離劍氣；劍氣在效果層 |
| W低位上揮 | 刀收在低位，向前上方撩出 | 刀不插入人物腿；刃線與前方敵人的上拋方向一致 |
| W拔刀突刺 | 刀先在鞘中，右手握柄、左手穩鞘口，抽刀後刃朝前突進 | 刀身逐漸離鞘；鞘留在腰間，不與刀一起飛出。人物前突可穿過敵人，不穿過地形 |
| W長刺抽回 | 長槍前方長刺穿過多敵人，沿原軸抽回 | 穿透為槍尖／桿的接觸路徑，不是人物穿身；被刺中者於抽回事件倒地 |
| W收杖上打 | 棍／杖／杵先收近身，前進一步，再由下往上重擊 | 重擊頭與桿軸都可讀；低位預備不穿地，擊飛方向較高 |
| W前射點放 | 一次短拉弦後射一箭 | 箭尾由實際拉弦手指位置釋放，箭從弓前方離開，不從臉／胸口冒出 |
| W前射滿蓄 | 維持完整拉弦，放開後射一支穿透擊退箭 | 箭頭保持前向；擊退與穿透由命中判定，不把多個敵人畫在箭圖裡 |

家康的鞘口與右手兩者都需逐格量測，完整出刀後才進入刀尖前突。出刀速度可以快，但不能跳過收刀／拔刀關鍵畫面。非弓雙手資料不要填到現有弓弦用的 `second_hand`。

## 滿蓄與空中攻擊

| 索引 | 武器運動 | 必須保留的畫面順序 |
| --- | --- | --- |
| W刀滿蓄 | 馬步近身收刀；施放時在腰部水平旋斬兩圈 | 集氣保持 → 第一圈 → 第二圈 → 收刀／回站；不是向地面風車式翻刀 |
| W槍棍滿蓄 | 頭頂舉起；施放時單手握尾端，在頭頂水平旋轉兩圈 | 換到尾端握持 → 第一圈 → 第二圈 → 降回可控位置；武器離開頭、兜角與念珠 |
| W朝天箭雨 | 滿蓄後蹲下、弓朝天空，射一支箭 | 朝天箭飛出畫面上緣 → 立刻降下獨立箭雨；每支落箭使用箭本體，不把整個雨區烘焙在一張弓圖 |
| W空中輕 | 刀槍棍弓在空中揮打近身 | 空中根點與地面分開；武器不因 20% 判定增益放大貼圖 |
| W空中落斬 | 刀槍棍高舉，再往地面方向下揮 | 上升舉起 → 下降下揮 → 接觸 → 馬步重落地 → 收招；刀刃／槍刃／棍頭位置可讀 |
| W空中三箭 | 朝前下方直射三支箭 | 弦釋放時三箭出現；沿同一前下方向，範圍是半個畫面寬；逐箭／同時發出的節奏待確認 |
| W跑步前揮 | 跑步時向前橫揮／掃出 | 跑步末步 → 武器前揮 → 接觸 → 減速收招；弓用弓身，不自動改成射箭 |

兩圈水平旋轉可使用骨架加武器透視圖，或由 3D／多視角製作後輸出影格。需要前、側、背方向與投影長度變化；只有一張竪直武器 PNG 在畫面平面轉 720°，無法正確表達頭頂／腰間環繞。保持真實本體長度，不能每格任意拉長武器。

## 抓摔時的武器

抓技不以刺穿敵人代替抓住。先收武器或轉成單手側持，空出抓取手；拋出前武器不穿過受害者。主握點、收納支點、可見與前後層需記錄。阿市收弓至背側／身側，弦未拉開；家康可收刀入鞘或安全側持。顯如和忠勝的長柄武器即使被遮住，也維持同一根完整武器。

## 武器層生成提示與檢查

```text
獨立可替換 <武器類型>，匹配已確認的形制與材質。
僅一件完整武器，真透明 RGBA，完整尖端與尾端，無人、手、文字、光軌或地面。
指定角度 <側視／斜向／背向>，保留實際物理長度與同一柄、刃、環、杵頭。
弓身不帶弦與箭；刀鞘獨立；箭獨立。提供可量測的握持位置與透明邊界。
```

接受條件：替換同類短／長武器後握點、雙手軸、武器前後層都正確；完整武器不裁斷；弦連在弓梢與指尖；拔刀鞘口不漂移；兩圈轉向完整；人物層中不存在第二把武器。
