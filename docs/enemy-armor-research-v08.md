# 敵兵圖鑑 v08：1560–1582 年武裝考證備忘

查核日期：2026-10-09。用途：敵兵外觀修正的證據界線；不是各軍團裝備普查。來源以博物館、政府文化財記錄、大学研究為主。本文沒有證據支持的裝備比例、全軍統一色與專屬制式，均不當成史實。

## 可直接採用的結論

- 一般槍足輕以長柄槍為主要識別，軍官／精銳的裝甲層次較完整。戰國中後期長柄槍重要性有館方說明；但「每軍團所有足輕都是固定 5–6 公尺槍」未獲證實。[S1]
- 陣笠不是年代錯誤。淺圓錐形、漆面、無巨大裝飾的陣笠可保留；不應全改成草帽。沒有資料能據此推出「1560 年所有足輕都戴相同陣笠」。[S3]
- 戰場軍官加兜有可靠實物依據。晚室町的筋兜＋護頸（錣）是穩健基準；指揮官不必人人配巨大角飾、面頰或後期異形兜。[S4–S5]
- 足輕減少與大將相同的大袖、華麗威糸、全身繁複護具，採較簡單胴甲、衣布可見與少量裝備差異，是本案的美術推定。**本次資料不能证明足輕多數無甲，也不能证明各藩的輕重甲比例。**
- 當世具足在戰國末期發展，板札胴與既有小札技法並存。1560 年代、1570–1582 年可逐漸調整裝備外觀，但不是全日本在某一年同步換裝。[S2]
- 制服色、兜式與腳部裝備先依職位、財力、作戰功能分層；不要把每個勢力製成一套有史料保證的近代制服。識別色與旗印屬遊戲設計時須這樣註記。

## 製圖可執行基準（明確標為本案美術推定）

1. foot：長槍清楚，甲以胴部為主，不自動配大將級大袖、面頰及華飾；頭部可有簡單兜或淺陣笠。衣物外露不等於全無防護。
2. ranged：弓／火繩槍及攜行配件應成為輪廓重點；不以持火器推定必無甲。已核可角色先保留。
3. standard bearer：先確保是符合審圖要求的垂直幟結構、可讀旗面，再處理旗紋。旗印與家紋不是每種場合必須相同的概念。
4. officer：兜鉢、眉庇和護頸可辨識；護具完整度高於普通足輕；可露臉但不以全面裸頭作為統一軍官模板。
5. miniboss：沿用已核可造型；未核可者以可靠的同時期實物提升身分差異，不任意加滿後世異形兜。

限制：本次未量化各勢力實際甲冑普及率，未完成每件參考物實物檢視；圖像重建、尺寸及配色仍須逐張審圖。原始研究 PDF 的文字已核對，但其小型圖版不作本次逐像素旗色依據。
