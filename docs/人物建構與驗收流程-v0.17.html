01｜鎖定本輪範圍與可回復的基線

入口
使用者最新修正與可啟動的前一版。
操作
逐條拆成可觀察的結果；記錄舊版包、定案素材及目前來源。先搜尋所有呼叫、快照欄位、操作表、展示、測試、包裝腳本；只改這個人物及必要共用根因。
交付物
本頁工作單、修改前截圖或短片、角色範圍／不在本輪的名單、前版 ZIP 與 SHA-256。

出口：每一條需求都有對應招式列與可重現的輸入。保留舊版與原始素材；不覆寫已定案信長／阿市來掩蓋本多問題。

不合格退回：需求沒有輸入步驟或「完成」無法判定 → 留在本關補齊；版本不明 → 先建立可回復基線。

02｜先定案身形、裝備與唯一武器

入口
人物定案圖或使用者明確指定的上一版；不以未定案候選取代。
操作
排正面、側面、背面、戰鬥站姿與同地平線比例板。記錄臉、頭身、肩胯、四肢、髮型、盔甲層次、家徽、握持位置與收納位置。逐張核對武器只有一把，雙手與槍身關係合理。
交付物
定案聯絡表、來源／生成提示／模型／種子、原 PNG SHA、與信長／阿市同地面比較圖。

本多沿用黑漆甲、紅繫帶、金色細節、鹿角兜、淡色念珠與單把蜻蛉切。槍尖與鈍槍尾不得混淆；下蓄力技是槍尾撞地。鹿角、念珠、槍長不能在不同招式忽長忽短。

出口：定案可被下一張圖直接引用；武器、身體與裝備輪廓固定。大型兵器與鹿角不納入解剖身高。

不合格退回：臉、甲、武器或比例漂移 → 回本關定案；不能只縮放整張圖救身材。

03｜從輸入列清單，不從「有幾張圖集」猜完整度

入口
定案造型與實際 F1 操作表。
操作
填下方逐招清單，對上 main.gd → battle.gd → frame_animation.gd → battle_view.gd → art_assets.gd / registration。每招寫出按下、保持、放開、方向鎖定、接段窗口、命中 tick、回復 tick、效果與音效。
交付物
每招的實際 action／combo／direction、圖源、實際來源格編號與 source 數、播放週期／停留時間、命中點與測試入口；借用來源必須明列。

「圖集 12 張」不等於「12 招」；也不等於一招實際播放 12 張。v0.16 的 charge/charged (6+6) 與一組 reactions (12) 是組圖概況，不能代表蓄力、釋放、受擊、擊飛、倒地、死亡各自達到 12 張。先補路由盤點，再判定哪些必須補畫。

套用敵兵／小王時的必填招式

下方 42 列是主角表；敵軍沿用站立、移動、受擊、擊飛、倒地、死亡、起身、抓摔／掙扎，玩家鍵盤專用列標不適用並寫理由。另從 Battle.ENEMY_ATTACKS / BOSS_PROFILES 逐個列出 AI action，將其測試觸發、實際圖源、hit tick、證據填入本關評論或附加清單。不能僅測 AI 隨機碰巧使出的一招。

  • 長槍足輕：直刺、橫掃、槍尾敲擊。
  • 旗手：旗桿戳刺、橫掃、下砸；旗面家徽與陣營一致。
  • 指揮官：斜斬、上挑、突進。
  • 弓兵／鐵砲手：面敵後退、瞄準、拉弦／裝填、發射、收勢；每階段都用相應姿勢，不能只倒滑站姿。
  • 小王：至少近身、長距、大範圍、抓丟四招，另有格擋、受擊、被擊飛／抗性、死亡；用固定場景各觸發一次，檢查裝備特色與玩家尺度。

出口：所有遊戲可到達的 action 有明確來源；測試可走到每個分支，未製作列仍標「待驗收」。獨有技可標不適用，但必須寫理由。

不合格退回：招式存在但落回舊站姿／不相干招式 → 回本關補路由；缺真正姿勢 → 回第 04 關。

04｜真正關鍵姿勢與自然節奏；蓄力保持與釋放分開

入口
逐招節拍表與定案造型。
操作
主要招式、行走、跑步、反應、抓摔、慶祝以讀得清楚為準；6 個真正關鍵姿勢可接受。先做起手、命中、收勢，再安排肩胯、手腳、兵器軌跡的中間姿勢；每張有可辨識變化。站立、短反應與保持段依用途記錄實際格數與接受理由。
交付物
逐招實際格數聯絡表（逐格編號並標 hit），原始透明 PNG、生成記錄、唯一來源格集合、完整 cycle 與各格停留 tick。

新製原圖以每格解剖站立身高至少 300 px 為目標，保留真正透明 alpha；縮放到遊戲後人物細節仍清楚。不得以放大低解析圖宣稱達標。既有較小素材若暫時沿用，需記錄實際身高與限制。

  • 各格依動作軌跡逐步變化；出手可以加速，但不能多數格近乎同圖、只最後兩格跳躍。驗收姿勢與節奏，不以湊張數代替動作。
  • 不可用複製、整張平移／旋轉、模糊插幀、影片抽取的壓縮圖充數。刀弧／槍風／震波是獨立特效，不掩蓋肢體缺幀。
  • 蓄力分「進入 → 穩定保持循環 → 放開後釋放 → 收勢」。長按 3 秒仍停在保持段，不可反覆播放已出手圖片。逐招註記實際 source 數、保持週期與接受原因，共用格不重複計為新姿勢。
  • 走路要有「開 → 窄 → 交錯 → 換腿開 → 窄 → 交錯」的真正腿位與重心變化。新 v0.19 敵兵完整 cycle 固定 60 tick（1 秒）：6 姿勢各 10 tick；若是 12 姿勢則各 5 tick。減少格數不縮短整輪，放開即站姿，不為走完整套而壓縮時間；退步只反轉步態方向。既有主角 12 張走路 12 fps／跑步 16 fps 的個別規格保留，跑步依實際完整週期驗收，攝影機保持平順。

出口：逐張與原速都能讀懂同一招；實際 source 數沒有重複充數。保持、出手、收勢用途分明，步態自然且完整 cycle 穩定。

不合格退回：比例漂移回第 02 關；動作缺幀、槍多長一把、腳步錯位回本關重畫；不能靠裁掉裝備修理。

05｜透明安全區與跨格污染，逐格擋下

入口
原始 RGBA PNG 與每張姿勢的來源編號。
操作
先找人物與所持兵器的完整連通區／合法分離零件，再決定 region，不能假設圖片完美平均分格。把所有實際 region 畫框，產生黑、白、棋盤格三種背景的接觸表。
交付物
region／source bounds、alpha 邊界與鄰格污染檢查、每格 PNG 裁圖預覽、原檔及任何派生圖的 SHA／處理記錄。
  • 人物、槍尖、鹿角、飄帶及合法半透明邊緣要完整落在自己的實際區域。等分格只是排版參考；只跨過虛擬格線、但人物輪廓仍可分離時，登錄完整 bbox 與 component_clip，不裁自己的武器，也不因此重畫。先用兩張 3×2 六格圖或單幀原圖，避免長槍硬塞 4×3。
  • 製作時在完整 alpha 輪廓外預留透明間距；以原生最大顯示比例測試，輪廓與鄰格不得接觸。推薦每幀至少 8 原始像素乾淨外圍；若來源不具此間距，改用完整連通區裁切／獨立幀貼圖／安全拷貝，不可讓採樣跨到鄰格。
  • 檢查不只 alpha > 24 的實心輪廓，還包含 1–24 的半透明殘邊。小槍尖、念珠與手指可能是小面積合法零件，不能一律刪除「小塊」。
  • 若僅 region 定義錯，改登錄。若兩個人物的合法輪廓真正重疊／相連，或人物、武器已在原圖的畫布邊界被裁掉，回第 04 關重畫；擴大 region 只會把別人的槍尖帶進來。
  • 派生清理圖必須保留原 PNG；逐張比對輪廓、坐標與處理記錄，禁止把抹掉槍尾當成去雜邊。原檔 hash 相同只能證明未改像素，仍要在原生裁圖中比對有無漏掉自身零件、帶入他人像素。

出口：每幀四邊都沒有另一張圖的零件；左右翻面、原生實際縮放、濾波後仍無黑白暈邊。自動像素掃描與人眼裁圖核對都留下證據。

不合格退回：region 選錯留在本關；原圖跨格相連或已裁斷回第 04 關。不能僅調整抽樣順序宣稱修好。

06｜固定解剖比例與腳底基準，長槍不能牽動身高

入口
安全裁圖與同角色站姿。
操作
逐張標示 feet / feet_global / body_height / body_heights / regions / frame_files。解剖尺度以同一人物的頭、軀幹與腿長判斷；蹲下、前傾、橫倒不代表整個人物縮小。
交付物
registration、同地面逐格疊影、站姿與最寬／最高／倒地姿勢的並列板。
  • 落腳是腳底接觸地面的位置；不取「圖格正中＋最下面」作通用值。跳起、擊飛、躺平要有明確世界位置基準。
  • 排除鹿角、槍尖、頭飾、馬尾、披風計算身體尺度。每格若需不同 body_height 必須有解剖理由，不可逐格亂調以湊外框。
  • 在固定世界坐標順播，軀幹大小不抽動，站地腳不整個滑動；獨立看角色與攝影機，先確認漂移出在素材 anchor 還是世界位移。

出口：同地平線與信長／阿市比例一致；動作銜接沒有忽大忽小、漂浮、突然沉地。長槍橫掃時人不縮小，槍豎起時人不放大。

不合格退回：固定錯誤可留本關校 anchor；真實身形改變回第 02／04 關重畫。

07｜接入戰鬥時間；圖片、命中、效果與聲音同一拍

入口
逐招素材、registration、輸入與命中時間表。
操作
從真實按鍵走到 action，再逐 tick 取樣。記錄實際使用來源與格號，不只讀宣告 count。攻擊 hit 前一格、hit 格、hit 後一格並列比對；英雄速度調整必須一併套入動畫時序。
交付物
實際來源／格數清單、逐 tick 事件與位移記錄、小型回歸測試、原生截圖。
  • 按住前進連按 J／K：停走並正確接第二、三段；停打才恢復前進。第三段只往前踏一步，不重複疊位移。
  • 「衝刺後按 K」與「原地按住 K 放開」分開測；不能把衝刺重手誤當蓄力。
  • 一個 hit 只結算一次，除非招式明列多段；空揮有破風聲，命中才有撞擊聲。格擋、無敵、同一波多敵命中也驗證不連發重複事件。
  • 本多滿蓄前衝逐 tick 平順位移；空地與命中各錄一遍。正常攝影機跟隨可平滑移動，不能每隔幾格跳 52 單位，也不能每段突進反覆加 camera shake。震動只留在確定撞擊點的有限事件。
  • 短按、34／35 tick 蓄力門檻兩側、長按、放開、被打斷、暫停／失焦／搖桿拔除後釋放都要有確定結果。

出口：手／武器抵達作用位置的那格才產生傷害與效果；保持階段不偷打，釋放階段不倒退回蓄力。單人與快照回放結果一致。

不合格退回：來源缺失回第 03／04 關；素材足夠但播放錯誤留在本關；圖與人位移脫節回第 06 關。

08｜反應、抓摔、死亡與過關不能共用一張敷衍

入口
主要攻擊可用、反應來源完整。
操作
測普通命中彎腰痛苦、擊飛、落地、存活倒地、起身、死亡躺平、暈眩、防禦、被抓掙扎、抓人與放開摔；再測過關前仍在空中、倒地、被抓及死亡隊友。
交付物
生命／action 轉換記錄、逐張反應表、死亡停留至少 3 秒與過關原生片段。
  • 受擊有軀幹反應與表情；不只全圖閃色／左右晃動。死亡落地保持躺平，不能回站姿或起身。
  • 倒地者不可抓；被抓者有掙扎，0.5 秒時一次 50% 掙脫判定，使用固定種子分別覆蓋成功、失敗。
  • 過關先落地／起身，再播個人慶祝；12 張約 6 fps、最後一張保持。活著的雙人都演出，台詞排隊，倒下隊友不喊。

出口：受擊、落地、死亡、起身、慶祝用途分明；死者不復活演出。使用共用姿勢時明列來源與差異，不能把一張 reactions 圖集全部勾完。

不合格退回：缺反應圖回第 04 關；落地或終態判斷錯留在本關。

09｜先量測聲音，再真人聽情緒與混音

入口
角色聲線定案、音效事件與命中時間。
操作
列出發力、受擊、蓄力、COMBO、完整招式名、登場、勝利，各自掛到 manifest 與觸發條件。逐句試聽再在戰鬥中混音試聽。
交付物
原 WAV／生成參數／SHA、音長與削波量測、分類試聽頁、實際戰鬥有聲片段。
  • 發力與受擊短喊 0.30–0.50 秒，至少 3 個不同 take；有力、偏高亢、迅速收尾，不是拉長呻吟或朗讀。完整台詞不套半秒限制。
  • 普通輕一、二與單次普通重手不喊；輕三、重二、COMBO、蓄力才喊。必殺可喊招式名。
  • 每類效果至少 3 種，輕／重刀命中各 5 種；不同 PCM、洗牌且相鄰不重複。長槍破風、槍命中、槍尾砸地、震波與擊飛落地要分辨得出。
  • 空揮、實際出手、命中、格擋事件分開。驗證 2P 不蓋掉 1P 台詞；旁白／過關按序播放。

出口：檔案時長、事件與隨機檢查通過，且有人實聽「力度、音高、長短、是否刺耳／被音樂蓋住」。只量到 0.4 秒不能認定熱血。

不合格退回：平淡、喘吟、截斷字尾回錄音／生成；播放過密或時點錯回第 07 關。保留舊語音引用時直接註記沿用。

10｜真實原生畫面，一招一次保留完整證據

入口
路由／時序／核心測試已通過；仍不是美術通過。
操作
以遊戲實際渲染與真實輸入路徑錄製；每招至少含站姿、起手、保持或出手、命中、收勢。用左右面向、近／遠景、空地／多人命中各覆蓋關鍵招式。
交付物
原生 60 fps 影片、有聲片段、每招實際格數標號圖、命中 tick、source 數與播放節奏記錄、拍攝腳本與原生日誌。

逐招驗收清單

每列至少記「實際 sheet／source 數、完整 cycle／每格停留 tick、命中 tick、測試或影片位置、結論」。同一張圖集服務多個 action 時，各列都要確認實際取樣與姿勢。下表依 v0.19 的姿勢與節奏標準填寫，並未預先認定本多已完成。

鍵盤：WASD 移動，J 輕手，K 重手，I 防禦，空白跳，L 抓摔，U 必殺，E 拾取。一般蓄力門檻目前 35 個 60 Hz tick；時序以 battle.gd 實際值及角色 hero_tick 為準。新增角色不得只把 action 名稱改對而沿用不相干姿勢。

每個可操作招式與反應的逐列驗收表
動作／狀態重現輸入／觸發必須看見的結果狀態與證據

本多此次兩個重點，獨立驗到放開後

下＋重手蓄力：槍尾震地

輸入：S＋按住 K → 蓄滿 → 放開。

  1. 舉槍：長槍直立、高舉；槍尖朝上、鈍尾朝地。
  2. 保持：周身氣場由弱到強，角色穩定蓄力，不重複提前撞地。
  3. 釋放：重心下沉，雙手發力，用槍底重擊地面。
  4. 命中：槍尾觸地的同一拍產生以人物為中心的全周衝擊波，附近雜兵震飛。
  5. 收勢：特效衰減，人物回站姿；波不重複產生，小王抗性按設計另驗。

證據須含正前／正後／兩側／範圍外敵人，證明範圍與擊飛結果；不能只拍一個正前方木樁。

一般滿蓄重手：平順向前衝

輸入：不按上下方向，按住 K → 蓄滿 → 放開。

  1. 出手後在多個 tick 連續前進，無瞬間階梯跳位。
  2. 角色大小、槍身、腳底基準穩定；不是靠鏡頭抖動表現加速。
  3. 空地不出現反覆震屏，正常攝影機跟隨不左右來回抽動。
  4. 撞到一人或多人時保留有目的的命中回饋，不把每 tick 接觸都當新撞擊。
  5. 兩個面向、共同攝影機與地圖邊界都確認；不能因一處停住就蓄積後瞬移。

留存角色 x／camera_x／shake 隨 tick 的記錄與原生片段；數值單調不取代人眼確認平順。
