# v0.14 招式與正式毛利軍

本版只細修信長、阿市與毛利軍。其餘角色造型保持現有版本。

## 戰鬥規則

- 信長跑步12張連續PNG，以16 fps循環；走路仍12 fps。放開即待機，不補完剩下步態。
- 六人輕手第三段在起手期間向面前共前踏42像素，原攻擊時序保持；被攻擊狀態打斷則停止踏步。
- 阿市下＋滿蓄重手在action tick28同時放出120度冰波與三箭，半徑維持320，每箭最多命中一人。箭出手位置來自當下弓手圖格。
- 阿市上＋重手只有一箭，短按25、滿蓄42基礎傷害，命中一人即消失並只凍結該人；沒有爆炸與穿透。無方向滿蓄仍是首敵爆裂冰箭。
- 重手刀氣與強招弧光加大，遊戲原有命中範圍保持，避免改美術時偷偷改平衡。
- 被抓敵人播放3張實際掙扎姿勢，在第30 tick作一次50%判定；成功即清掉抓取雙方關係，沒有成功則沿原規則最多抓180 tick。網路重播使用同一確定性判定。
- 倒地、起身中、被拉扯或在空中的敵人不能被抓。
- 毛利小王有短距砸擊、長鏈拉近追打、大範圍橫掃及近身抓摔四招，抓摔第26 tick捕獲、第54 tick摔出。裝備沿定案鎖鎌兵；體型比普通兵魁梧但仍接近玩家。

## 逐張素材

毛利來源是 `assets/enemies-v0.8/mori.png`，普通兵黑色陣笠、指揮官實用兜、米袖與青腰帶保持辨識。弓兵沿同軍遠程兵服裝改持弓及箭筒。旗幟加「一文字三星」：一條橫線在上，下面三個實心圓呈一上二下。家徽參考日本文化廳收錄的[萩博物館藏御紋入盃](https://online.bunka.go.jp/heritages/detail/116136)。

原始PNG保存在 `game/assets/v14`，由內建imagegen生成／定點修稿，保留原始位元組與真正alpha。最終 `prompts.json` 彙整所有正式PNG的完整提示、來源路徑及SHA；小王與跑步完整來源另存 `artifacts/art-native-v14/boss-run-full-provenance.json`。`registration.json` 明列區域、腳底及解剖身高，武器／旗杆不參與身高縮放。落選原圖另存候選目錄，不納入試玩套件。

普通兵每種6張走路、3張受擊、3張掙扎、6張倒下；長槍兵／旗手／軍官各三招，每招6張，弓兵與鐵砲各6張射擊。小王待機6、走路12、四招各6、受擊6、倒下6。角色被凍住時保持當下姿勢，死亡最後保持水平躺下。毛利場景營旗也補家徽，使用6張布面變化圖以5 fps循環，旗杆及底座固定。

## 聲音與配樂

新增17段語音：阿市連段4、蓄力4、痛苦3；毛利小王攻擊3、強招3。普通重手及未蓄力的方向／空中／衝刺重手不喊。語音由本機Qwen3-TTS VoiceDesign產生，生成提示與檔案信息留在 `game/audio/v14`。

原創80秒循環配樂為144 BPM、48小節、多段太鼓／撥弦／笛音編曲；編曲與合成方法在 `scripts/generate-bgm-v14.py`，完整樂譜事件、來源及技術指標在 `game/audio/v14/music.json`。遊戲開局播放，暫停保留位置，結束／返回選單停止。

## 驗證與限制

`node scripts/test-v14.mjs` 檢查核心、輸入、網路、音訊、逐張來源及比例路由；加 `--render` 產生真正Godot動態截圖與六職業動作板。正式圖像驗證要求 `--require-v14`，缺正式素材時拒絕通過，不用舊素材冒充。

`scripts/verify-package-v14.py` 比對壓縮包每個檔案與來源，再於新解壓目錄跑測試。原生動態驗證使用固定腳本輸入與明列的AI場景設定；尚不代表實體搖桿震感、雙人手感或跨網路驗收。語音情緒與配樂聽感尚未完成人耳聆聽；目前確認的是解碼、時長、音量峰值、變化輪替、配樂循環邊界與遊戲播放生命週期。
