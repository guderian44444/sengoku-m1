# v0.22 武器與角色存檔

目前信長、阿市、本多各五款武器；其他已選人物暫時共用相容刀／槍裝備，不表示其人物細節重畫完成。預設為打刀、梓丸木弓、蜻蛉切初品，出陣不會空手。三家武器不可混用。戰場按拾取鍵拿起同類武器，會加入個人收藏並裝備；已裝備的重複物件保留在地面給隊友。選角頁可重新裝備任何已取得的同類武器。

## 歷史與美術

十五款名稱、形制說明、遊戲階位、加成與來源在 `game/core/weapon_catalog.gd`。刀包括打刀、大般若長光、宗三左文字、壓切長谷部、童子切安綱；槍包括直槍、片鐮槍、十文字槍、日本號、蜻蛉切；弓包括梓丸木弓、竹藤弓、黑漆弓、朱漆弓、重藤弓。弓為有史料的不同形制，並非宣稱是阿市的五把遺物。參照物跨古代、戰國至近世；階位、顏色裝具、傷害和元素為遊戲改編，不是對歷史名物的優劣排名。

圖源由內建 image_gen 生成透明 RGBA 原圖，保留於 `sources/`，提示記錄在 `generation.json`。十五張獨立 PNG 不改原像素或 alpha，僅裁切，實體長度至少 600 原生像素。`registration.json` 保存原圖 SHA、裁切區、crop-local 握點、上下尖端、原生長度及輸出 SHA。日本號保留使用者選定的新版長槍圖第四欄；蜻蛉切支援獨立圖源，按本版指定的槍桿 180 公分、槍刃 43.7 公分、刃寬 3.7 公分登錄，世界長度為 223.7，其餘長槍為 335。這是本版遊戲比例規格，不表示其他史料記載皆相同。弓未烘焙弦或箭，執行時以弓梢及拉弦手繪弦。`weapon_renderer.gd` 只對 `layered_weapon=true` 的新版人物繪製武器，避免舊版人物重複兩把武器；人物手部依登錄遮罩覆繪在武器前。長槍砸地的 `weapon_grounded` 影格會沿槍桿滑移握點，讓槍底貼地，同時維持原手掌位置與完整槍長。

## 掉落與傷害

小王有 65% 機率掉落擊殺者可用的較高階武器（最多高兩階）；大王保證掉較高階武器（最多高三階）。已取得最高階則不再掉升階武器。掉落類型取決於致命傷玩家的武器種類；隨機狀態在權威世界快照中，同種子回放會得到同一結果。訓練場不會掉持久化裝備。

武器加成套在持武器近戰及箭矢上，包括加傷、距離、推力、部分高階元素；不把阿市的踢擊或短針視為弓箭攻擊。箭矢發出時保存傷害、元素及推力，途中換武器不會改已射出的箭。普通冰箭仍然單體命中，不會因冰屬性變成全穿透。信長普通重手視覺劍氣與 200／230 基礎命中距離共用武器距離加成。

## 存檔範圍

正式單人／同機雙人自動存 `user://characters-v1.json`，每 2 秒檢查有無變更，拾取／擊殺立即檢查，退出戰鬥或程式也保存；暫停有「保存人物」。以 1P／2P 和武將分開，共十二筆位置，同一武將雙人不會互蓋。

保存總積分、永久生命加成 `max_hp_bonus`（現版預設 0）、已裝備的武器 ID、已取得武器。基礎生命仍隨難度；下次出陣滿血三條命，下一個加命門檻由總積分推導。不保存關卡、當前 HP、剩餘命數、敵人、怒氣、護符、掉落或戰鬥狀態。工程訓練、素材展示及工程 IP 連線不寫正式角色檔。

存檔先寫暫存檔、重新解析驗證，再將原有效檔改名為 `.bak` 並換入新檔。主檔損毀則讀有效備份，下次保存保留 `.corrupt-*` 原件；兩份都無效或主檔為未知版本則保留全部原檔並禁止自動覆寫，畫面顯示原因。未知版本主檔即使附有有效的舊版備份也不會被覆蓋；保存前再次檢查版本，保護遊戲開啟後由新版寫入的檔案。測試均使用儲存庫 artifacts 的獨立路徑與 APPDATA，不改玩家真存檔。

## 可重跑驗證

在儲存庫根目錄：

```powershell
node scripts/test-v19.mjs --only=weapons_save_v22,loadout_menu_v22,weapon_render_v22 --render-v22
node scripts/test-v19.mjs --only=hero_layers_v22 --render-heroes-v22
node scripts/test-v19.mjs --only=battle,wire,progression_v21,projectile_v12,tadakatsu_combat_v17,knockdown_v18,training,hud_v19,menu_v20,engineering_menu_v21,render_items_v21
python scripts/register-weapons-v22.py --check
```

第一個命令覆蓋歷史 catalog 數量與來源、同類拾取、預設／升階裝備、命中加成、單體冰箭、彈體快照、PRNG 回放、實際擊殺掉落、雙角色存檔、檔案損毀回復、未知版本拒絕、正式選角與暫停接線、原生武器繪圖。第二個命令要求三人完整登錄，逐一驗證四十種實際動作皆使用 v22 六格圖與新圖頭像；繪出各動作六個時間點，包含武器、握手遮擋與既有特效。原生畫面保存在 `artifacts/native-v22/hero-actions/`，`coverage.json` 列出實際來源、影格與時間點。蓄力持續、格擋、凍結等刻意停留的姿勢會有重複影格。開發中的單獨 Godot 腳本可附 `-- --available` 驗尚未齊全的素材，或以 `-- --hero=oichi --actions=heavy2,dash_strike` 只重驗有改過的動作；局部結果另存 coverage 檔並標記 partial，不代表整套驗收。人物握點、刀路、換裝前後遮擋仍要連同逐招畫面目視。舊版素材測試透過 `tests/legacy_battle_view.gd` 僅移除該測試實例的 v22 圖層，驗證仍保留的舊版路由；新版驗收必須使用第二個命令的實際正式 renderer，不得拿舊版測試替代。
