## 播放時序
- 進首頁 t=0 播 title_intro.ogg，一次性 14.805895692 秒。
- t=14.705895692 開始 title_loop.ogg，同時將 intro 音量線性 1→0、loop 0→1，交叉淡化 0.100 秒。
- t=14.805895692 停 intro，loop 繼續，勿從頭重啟 loop。
- loop 每 128.135600907 秒循環，之後不再播 intro。第一輪迴圈末→次輪開頭約 t=142.841496599。
- intro 已含 0.6 秒淡入；音檔已乘 0.65 音量，不要重複套增益。
- 官方原始 MP3 loop 邊界數值有跳幅；本交付 OGG 頭尾各做 3ms 淡化避免硬跳幅，不更動總時長。不得宣稱原曲循環已經主觀聽感驗收。
- 關閉首頁或進遊戲時由音樂管理器淡出，避免與關卡 BGM 疊播。一般切換首頁子選單不重啟 intro。
